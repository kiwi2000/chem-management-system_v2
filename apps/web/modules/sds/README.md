# SDS 作成モジュール

特定のお客さんにだけ渡すオプション（決定 0016）。本体はこのフォルダを直接読まず、`scripts/gen-modules.mjs` が作る
差込口の一覧（`../registry*.generated.ts`）だけで結ぶ。SDS なし版の配布物には、このフォルダごと入らない。

- 有効にする: 環境変数 `CHEM_MODULES=sds`（Railway のサービス `sds`）か、配布物の `enabled.json`。dev・typecheck・test は常に全部
- 画面: `/sds`（入口）、`/sds/ghs`（GHS 分類データの取り込みと記録）
- API: `/api/modules/sds/ghs/import`（POST、管理者だけ）、`/api/modules/sds/ghs/releases`（GET）
- 物質の詳細に「GHS 分類（出典別）」の欄を差し込む（`substance-section.tsx`）
- 文言は `messages.ts`（両言語）。本体の辞書には入れない
- 表は本体の DB の `sds_ghs_*`（`prisma/schema.prisma` の末尾）。お客さんに渡すときは、権利の無い出どころを
  `sds_ghs_sources` から消せば、公表・項目・分類まで cascade で消える

## 中身

| 場所                    | 役割                                                                                |
| ----------------------- | ----------------------------------------------------------------------------------- |
| `ghs/catalog-data.ts`   | 危険有害性クラス・区分のカタログ（共通コード・日本語名・英語略号・既定の H コード） |
| `ghs/nite.ts`           | NITE 統合版（区分一覧）と根拠一覧の読み手。1 セルの読み方は `nite.test.ts`          |
| `ghs/eu-annex-vi.ts`    | EU 附属書VI（ECHA の Excel の History シート）の読み手。版と適用日は行ごと          |
| `ghs/import-service.ts` | 差分（追加・変更・変わらず・見当たらず）と反映。出どころ・カタログの初期データ      |
| `ghs/query.ts`          | CAS × 判定対象日で分類を引く（物質の詳細、のちの混合物計算）                        |
| `ghs/adopt.ts`          | 国ごとの出典の採用順で、物質 × クラスの分類を 1 つに決める（自社判定が最優先）      |
| `ghs/countries.ts`      | SDS の対象の国（管轄）の一覧                                                        |
| `api.ts`                | モジュールの API（取り込み）。GHS データの API は `ghs-data-api.ts`                 |
| `pages/` `components/`  | 画面                                                                                |

設計と経緯: `docs/steps/S23_SDS_GHS分類データ.md`、原典の検証: `docs/GHS分類の原典/検証結果_DB項目.md`。

## 変更履歴（このモジュールの分。本体の変更履歴には書かない）

### 2026-09-28（3回目）　GHS データの画面、自社判定、国ごとの採用順

- メニューの「SDS 作成」を親にして、「GHS データ」と「GHS 取り込み」を下に置いた
- `/sds/ghs-data`: 物質 × 危険有害性クラスの表（共通の表。物質コード・名称・CAS で絞り込み・並べ替え）。
  上で「SDS の対象の国」を選ぶと、その国の採用順で採った分類に変わる。列は 39 あるので横に流す（列ごとの最小幅を共通の表に足した）
- 行末の鉛筆から**自社判定**を登録できる（物質を編集できる人）。クラスごとに該当（区分・標的臓器）／区分に該当しない／分類できない／
  分類対象外を選び、効く国（全ての国・いま選んでいる国だけ）と理由（必須）を付けて保存。出典より優先され、表では「自社」の印と色で分かる
- 「出典の採用順」（管理者だけ変えられる。誰でも見られる）: 国ごとに出典を上下に並べ替え、「分類できない」も次で埋めるかを出典ごとに選ぶ。
  保存が無い国は既定（その国の出典が先頭、あとは出典の並び順）
- 物質の詳細の比較表（出典別）は変えていない。採用の結果はこの画面だけ
- 画面の上にタブ「物質｜NITE …｜EU …」。出典のタブは**出典の項目をそのまま**（行＝識別子・版。CAS・EC 番号・条件・適用開始／終了・
  CAS で結び付く物質コード・クラス 39 列）。物質マスタに無い CAS の項目や CAS の無い項目（EU の一群の項目）もここでは出る。
  取り込み済みの出典だけタブになる。物質との結び付きは CAS のまま（手動リンクは作っていない。2026-09-28 指示）
- 表 2 つを足した（`sds_ghs_overrides`、`sds_ghs_adoption_rules`。移行 `20260928160000_sds_ghs_overrides_and_adoption_rules`）

### 2026-09-28（2回目）　EU 附属書VI の取り込み、最終確認の表示

- 出典に「EU CLP 附属書VI（調和分類）」を足した。ECHA の Excel（History シート付き）を `/sds/ghs` で選ぶ。
  いま効いている版と、これから効く版（将来の ATP）を取り込み、適用開始日・終了日は行ごと。同じ適用日で中身が変わったら訂正としてその場で書き換える
- 物質の詳細の欄に「最終確認: 〈公表〉（公表日、取り込み日）」を出す。「出どころ」は「出典」に改めた
- 濃度限界・M 係数・ATE は原文のまま項目に持つ（`limits_raw`）。解析は段 1
- 物質の詳細の欄: 「状態」の列をやめ、区分の列に「区分／出典の言葉（区分に該当しない・分類できない・分類対象外）／データなし」を出す。
  チェックボックス「非該当」「データなし」で行を足す。見出しの「判定対象日」は「データ取得日」（出典ごと）に変えた
- 取り込みの反映で、版を持つ出典（EU）の「前の版を閉じる」処理を行ごとの問い合わせからまとめ読みに変えた
  （4,000 回超の問い合わせがトンネル越しで時間切れになった）

### 2026-09-28　GHS 分類データの土台（S23 段 0）

- NITE の政府 GHS 分類（統合版）を取り込めるようにした。`/sds/ghs` で区分一覧の Excel（任意で根拠一覧も）を選び、
  「下見」で追加・変更・変わらず・見当たらず・要確認の件数を見てから「取り込む」
- 取り込んだ分類は、物質の詳細の「GHS 分類（出典別）」に出る。既定は該当する項目だけ、ボタンで全項目
- 分類の行ごとに GHS 改訂版と分類年度を持つ（根拠一覧を一緒に取り込んだとき）
- まだ無いもの: EU など他の国の読み手、濃度限界・M 係数、物質ごとの上書き、国ごとの採用規則、混合物の分類計算

### 決めたこと（利用者に確かめた）

| 項目 | 決まり |
| --- | --- |
| 選ぶもの | **差出元**（どこからのお知らせか）と**宛先**（だれ宛てか）の 2 つ |
| 選べる組織 | どちらも、投稿する人の組織と、その上の組織。最初は自分の組織が選ばれている |
| 宛先で見える人 | 選んだ組織とその下の人だけ（ほかの部・取引先には見えない） |
| 宛先の「全員」 | 取引先も含めた全員に見える。選べるのは「他人のお知らせも編集・削除できる」人だけ |
| ホームの見出し | 差出元で分ける（「〇〇からのお知らせ」。並びは組織の木の上から、差出元の無いものは最後の「その他のお知らせ」）。各行の右に「〇〇宛て」 |
| 今あるお知らせ | 宛先は全員（今までどおり全員に見える）、差出元は投稿した人のいまの組織 |

### 作るときに決めた点

- 直すときは、いま付いている差出元・宛先をそのまま残せる（異動したあと・管理する人が他人の分を直すとき）。新しく選ぶなら自分の組織とその上だけ
- お知らせを管理できる人の一覧（`/news`）には全部が出る。ホームは管理する人にも宛先どおり
- 宛先の外のお知らせは、編集できない人が直接開くと 404
- ホームの各行の右は、投稿者の今の組織をやめて宛先にした（差出元は見出しに出ているため）
- 組織の無い人は投稿できない（画面に案内を出し、保存ボタンを押せない。API は 400）
- 組織は印を付けて消すので、宛先の組織を消しても「全員」には広がらない。外部キーも行ごと消す動きを止めた（RESTRICT）

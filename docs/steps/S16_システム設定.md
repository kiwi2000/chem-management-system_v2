# S16 — システム設定

確定日: 2026-08-14（CAS欄の2項目のみ。他の設定は必要になった時点で追加する）

運用の方針が現場ごとに違う部分を、管理者が画面から切り替えられるようにする。
値は `system_settings` テーブルに文字列で持ち、`packages/shared/src/settings.ts` で型付きに読み替える。

## 現在ある設定

| 設定 | キー | 既定 | 効果 |
|---|---|---|---|
| CAS番号を必須にする | `substance.cas_required` | **オフ** | オンにすると、CAS空欄では物質を保存できない（400） |
| CAS番号の形を強制する | `substance.cas_format_enforced` | **オフ** | オンにすると、`数字-数字-数字` でない値は保存できない（400）。オフなら警告だけ |

**既定はどちらもオフ**。ポリマー・UVCB・組成不明品・企業秘密物質を扱えるようにするため。
厳密に管理したい運用では両方オンにする。

## 動作の決めごと

1. 未設定のキーは既定値にフォールバックする。初期データの投入は不要
2. **形式を強制しているときは、形式の警告は出さない**（エラーで弾かれるため二重に出さない）
3. 必須にすると、物質の登録画面で CAS 欄に「（任意）」が消え、ブラウザ側でも必須になる
4. 設定を変えても**既存データは検証し直さない**。次に保存したときから効く
5. 設定の変更は監査ログに残す

## 権限

**設定は参照も変更もシステム管理者だけ。** 一般ユーザーには設定画面を見せない。

| 操作 | 必要な権限 |
|---|---|
| `GET /api/settings` | `ADMIN` |
| `PUT /api/settings` | `ADMIN` |
| `/admin/settings` 画面 | `ADMIN`（`app/admin/layout.tsx` のガード） |

### 一般ユーザーの画面が設定値を必要とするとき

API を緩めてはいけない。**サーバーコンポーネントで `getAppSettings()` を呼び、必要な値だけを
クライアントコンポーネントに渡す**。物質の登録・編集画面がその形になっている
（`app/substances/new/page.tsx` / `app/substances/[id]/page.tsx`）。
これなら設定一式がブラウザに渡らず、画面は設定に追従できる。

## 検証結果（実測）

設定4通り × 入力3種類を実際に登録して確認した。

| 必須 | 形式強制 | 空欄 | 非CAS（POLY-9999） | 正しいCAS |
|---|---|---|---|---|
| オフ | オフ | 201 | 201（警告） | 201 |
| **オン** | オフ | **400** | 201（警告） | 201 |
| オフ | **オン** | 201 | **400** | 201 |
| **オン** | **オン** | **400** | **400** | 201 |

- エラー文言: 空欄 →「CAS番号は必須です（システム設定で変更できます）」／
  非CAS →「CAS番号の形が正しくありません（例: 7439-92-1）。システム設定で緩められます」
- 必須オンにすると登録画面のラベルから「（任意）」が消え、`required` 属性が付くことを DOM で確認
- 権限: 閲覧のみユーザー → GET **403** / PUT 403、管理者 → GET 200、未ログイン → 401。
  閲覧のみユーザーで `/admin/settings` を直接開くと「権限がありません」だけを表示
- 閲覧のみユーザーでも物質の詳細画面は開け、CAS欄が設定どおりに描画される（設定はサーバー側で解決）
- DB に `BOOLEAN` 型として2件保存されることを確認
- 単体テスト6件（4通りの組み合わせ）を追加。typecheck / lint / prettier / build / テスト51件すべて通過

## 設定を増やすときの手順

1. `packages/shared/src/settings.ts` の `AppSettings` / `DEFAULT_SETTINGS` / `SETTING_DEFS` / `settingsSchema` に足す
2. `packages/shared/src/i18n/ja.ts` の `settings` ブロックに名前と説明を書き、`en.ts` にも入れる
3. `apps/web/app/admin/settings/page.tsx` に入力欄を足す
4. 設定を読む側は `apps/web/lib/settings.ts` の `getAppSettings()` を使う。
   **一般ユーザーの画面で使うときはサーバーコンポーネント経由**にすること（API は管理者専用のまま）

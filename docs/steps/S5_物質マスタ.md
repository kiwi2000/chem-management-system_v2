# S5 — 物質マスタ

確定日: 2026-08-14

以降のマスタ画面（金属換算係数・製品・法規制・情報源）はこの画面の型を踏襲する。

## データ項目

### 物質
| 項目 | 型 | 必須 | 備考 |
|---|---|---|---|
| 物質コード | 20文字 | ○ | ユーザーが付与。正規化（全角→半角・大文字化）して一意 |
| CAS番号 | 20文字 | 設定次第 | 既定は**任意**。ポリマー・UVCB・企業秘密物質を登録できるようにした。<br>必須にするか・形を強制するかは**システム設定で切り替える**（`docs/steps/S16_システム設定.md`） |
| 状態 | 使用中 / 廃番 | ○ | 廃番でも一覧には出る |
| 備考 | 自由記入 | − | 日本語のみ。検索対象に含める |

### 名称
主名称1件（日本語必須・英語任意）＋別名 最大100件。英語が未入力なら英語表示でも日本語を出す。

### 官報公示整理番号
複数登録できる。区分は **化審法（MITI番号） / 安衛法 / その他**。既定は化審法。
同一物質・同一区分に同じ番号は登録できない。

### 拡張属性
システム管理者が「キー・項目名・種類（数値/テキスト）・既定の単位・表示順」を定義し、
物質ごとに値を入れる。数値には単位を個別指定できる。

## 動作の決めごと

1. コードの正規化は **全角→半角 → trim → 大文字化**。突合・一意判定は正規化値で行う
2. CASの正規化は **全角→半角 → 各種ハイフン（`‐ ‑ – — − ー －`）を `-` に統一 → 空白除去 → 大文字化**
3. **CAS番号は表示用の値も正規化後に揃える**（全角で入力されても一覧では半角で並ぶ）。
   コードは業務キーなので原文の大小文字を残す
4. CASが一般的な形（`数字-数字-数字`）でなければ**警告**。保存は通す（暫定番号を許すため）。
   システム設定で「形を強制する」をオンにすると、警告ではなくエラーで止める
5. CAS空欄も既定では通す。システム設定で「必須にする」をオンにするとエラーで止める
6. 同じCASの物質が既にあれば**警告**。保存は通す（同一CASを意図的に認めているため）。
   **登録時だけでなく更新時にも出す**（v1は登録時しか見ていなかった）
6. 警告が出たときは一覧に戻らず、その場に留まって内容を見せる
7. コードが重複したら 409 で止める
8. **削除（論理削除）すると、同じコードを再登録できる**。正規化コードにIDを付けて退避する（v1はできなかった）
9. 検索はコード・CAS（どちらも正規化値）・主名称・別名・備考を横断する
10. 一覧はコード昇順・1ページ50件
11. 拡張属性は、値が空の項目は保存しない。種類（数値/テキスト）と値の整合はサーバーで定義と突き合わせる
12. 項目定義は、値が入っている状態では**種類を変更できない**（据え置く）。キーは常に変更不可
13. 項目を「使わない」にすると新規入力欄からは消えるが、**編集画面では入力済みの値が見える**ように取得する

## 権限

| 操作 | 必要な権限 |
|---|---|
| 一覧・詳細・検索 | `SUBSTANCE_VIEW` |
| 登録・更新・削除 | `SUBSTANCE_EDIT` |
| 項目定義の閲覧 | `SUBSTANCE_VIEW`（物質の編集画面が使うため） |
| 項目定義の追加・変更・削除 | `ADMIN` |

編集権限が無いときは一覧の操作ボタンを出さず、詳細画面は `<fieldset disabled>` で読み取り専用にする。

## 検証結果（実測）

- **正規化**: 単体テスト20件。全角数字・6種のハイフン・全角スペースを吸収して同じ値になることを確認
- **保存**: コード `pb-001` → 正規化 `PB-001`／CAS `７４３９－９２－１` → `7439-92-1` で保存。
  名称・別名・整理番号・拡張属性（数値 327.5℃ / テキスト Pb）が正しい列に入ることを DB で確認
- **検索**: `7439-92-1` / `７４３９－９２－１` / `7439‐92‐1`（U+2010）/ `pb-0` / `lead` / `金属`（備考）すべて1件ヒット
- **警告**: 同一CASで登録 → `同じCAS番号の物質が既にあります: pb-001`／
  `POLY-0001` → 形式の警告／CASなし → 警告なし。いずれも 201 で保存される
- **更新時の警告**: 既存物質を更新 → 同一CASの警告が返ることを確認（v1の抜けを修正）
- **コード重複**: 409 `物質コード「pb-001」は既に使われています`
- **削除→再登録**: 削除 200 → 同じコードで再登録 201 → 一覧に再登録分だけが残る
- **権限**: 閲覧のみユーザー → GET 200 / POST・PUT・DELETE すべて 403 /
  `/api/admin/substance-property-defs` 403。物質権限を持たないユーザー → GET も 403
- **項目定義**: キー重複 409、キー形式違反 400
- **多言語**: 英語に切り替えると一覧・編集画面が全て英語。英語名のある物質は英語名、無いものは日本語で表示
- **モバイル幅(375px)**: 一覧・編集とも横スクロールなし（表は枠内でスクロール）
- コンソールエラーなし（テストで意図的に出した 401/403/409 のみ）
- typecheck / lint / prettier / build / テスト45件すべて通過

## 勝手に決めた点

- **CAS番号の表示値を正規化後に揃えた**。全角で入力されたCASが一覧にそのまま並ぶと読みにくいため。
  CASは表記が一つに決まる識別子なので原文を残す意味が薄いと判断した（コードは原文を残す）
- 検索で `7439 92 1`（ハイフンの代わりに空白）はヒットしない。空白は除去する仕様のため
- 一覧の主名称の後ろに別名の件数を `+1` で出す

## まだやっていないこと

- この物質を含む製品の逆引き（S11 で詳細画面にカードを足す）
- 廃番の物質を組成の新規行で選べなくする制御（**S8 の組成エディタ側で実装する**）

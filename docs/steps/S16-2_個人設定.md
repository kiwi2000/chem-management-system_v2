# 個人設定（利用者ごとの設定）

確定日: 2026-08-14

## 「システム設定」との違い

名前が似ているので、置き場所を分けている。

| | 個人設定 `/preferences` | システム設定 `/admin/settings` |
|---|---|---|
| 誰の設定か | **その人だけ** | **全員に効く** |
| 誰が変えられるか | 本人（ログインしていれば誰でも） | システム管理者のみ |
| 中身 | 言語・テーマ | 入力チェックの厳しさなど |
| API | `PUT /api/preferences` | `GET/PUT /api/settings` |

呼び方は**「個人設定」**（英語は Preferences）にした。「設定」だけだとシステム設定と紛らわしいため。

## 入口

トップバー右の**歯車アイコン**から開く。サイドバーには出さない（業務のメニューと性質が違うため）。

## 中身

### 言語
これまでトップバーにあった切替をここへ移した。**ログイン画面には残してある**（ログイン前に選べる必要があるため）。

### テーマ
14種類。選んだ瞬間に保存して画面へ反映する（保存ボタンは置かない。見た目は押した結果が見えたほうが選びやすい）。

| テーマ | 内容 |
|---|---|
| 端末の設定に合わせる（既定） | OSが暗い配色ならダーク、そうでなければライト |
| ライト | 白を基調にした標準の配色 |
| ダーク | 暗い背景 |
| スカイ | 明るい空色。事務作業向けのすっきりした配色 |
| オーシャン | 深い青を基調 |
| フォレスト | 緑を基調 |
| セピア | 紙のような温かみのある配色 |
| サンセット | 温かいオレンジを基調 |
| ローズ | 少し濃いピンクを基調 |
| **ネイビー** | **トップバーと表の見出しを紺色に** |
| **ティール** | **同じく青緑に** |
| **ワイン** | **同じく深い赤紫に** |
| **チャコール** | **同じく濃い灰色に（色味なし）** |
| 高コントラスト | 白黒をはっきりさせ、枠線を強く出す |

### トップバーと表の見出しの色

`--header` / `--header-foreground` / `--table-head` / `--table-head-foreground` の4つで決まる。
**既定では `--header` は `var(--background)`・`--table-head` は `transparent`** にしてあるので、
何も指定しないテーマは本文と同じ色のまま（従来どおり）になる。濃くしたいテーマだけこの4つを上書きする。

濃い色を敷くと、中の要素が読めなくなるものがあるので次のようにしてある。

- 表の `th` は既定で `text-foreground` を持つため、`[&_th]:text-inherit` で打ち消して見出しの文字色を継承させる
- 背景を持つボタン（ログアウトなど）は文字色を `text-foreground` に固定する。継承すると白地に白文字になる
- 枠線だけのバッジ（「参照のみ」）は `border-current text-inherit` にして継承させる
- 並べ替えの見出しボタンは、色を変えるのではなく `hover:opacity-75` で反応させる

## 動作の決めごと

1. 保存先は **Cookie ＋ ログイン中なら本人の設定**（`users.preferred_locale` / `preferred_theme`）。言語と同じ形
2. 優先順位は **Cookie → 本人の設定 → 既定**
3. テーマは**サーバー側で決めてから描画**する。開いた直後に色が入れ替わるちらつきが起きない
4. 「端末の設定に合わせる」のときだけ、描画前に走る小さなスクリプトで OS の設定を見て `.dark` を付ける
5. `PUT /api/preferences` は**認証不要**（ログイン画面で言語やテーマを選べる必要があるため）。
   副作用は Cookie と本人の設定だけで、業務データには触れない
6. 知らないテーマ名・言語コードは 400 で弾く

## テーマの足し方

1. `apps/web/app/globals.css` に `.theme-<名前>` を足し、色の変数を上書きする
   （トップバーや表の見出しを濃くするなら `--header` 系4つも指定する）
2. `packages/shared/src/theme.ts` の `THEMES` と `THEME_SWATCHES` に足す
3. `packages/shared/src/i18n/ja.ts` の `preferences.themes` / `themeDescriptions` に名前と説明を書き、`en.ts` にも入れる

## 検証結果（実測）

- 全テーマで `<html>` のクラスが期待どおり変わることを確認
  （light → なし / dark → `dark` / 他 → `theme-<名前>`）
- CSS変数の実測値: セピア `--background: oklch(0.968 0.014 85)`、オーシャン `oklch(0.985 0.008 230)`、
  フォレスト `oklch(0.98 0.01 145)`、スカイ `oklch(0.99 0.006 220)` / `--primary: oklch(0.6 0.13 230)`、
  サンセット `oklch(0.99 0.012 70)` / `oklch(0.62 0.15 55)`、ローズ `oklch(0.985 0.008 350)` / `oklch(0.55 0.17 355)`、
  高コントラスト `--border: oklch(0.35 0 0)` と、それぞれ別の配色になっている
- スカイを選んだ状態で物質一覧を開くと、表の罫線 `oklch(0.895 0.03 220)`・サイドバーまで配色が効いている
- ヘッダーが濃いテーマ4種の実測（トップバー / 表の見出し）:
  ネイビー `oklch(0.3 0.07 258)` / `oklch(0.42 0.06 256)`、ティール `oklch(0.36 0.07 196)` / `oklch(0.47 0.06 195)`、
  ワイン `oklch(0.32 0.09 12)` / `oklch(0.44 0.08 12)`、チャコール `oklch(0.28 0 0)` / `oklch(0.4 0 0)`。
  文字色はいずれも `oklch(0.97 …)` で、本文は明るいまま
- **既存テーマに影響が無いことを確認**: ライトはトップバー `oklch(1 0 0)`・表の見出しは色なし・文字は `oklch(0.145 0 0)` のまま。
  ダークは表の見出しだけ `oklch(0.269 0 0)` になり区切りが見える
- 濃いヘッダーで読めなくなっていた2か所（ログアウトボタンの白地に白文字、表の見出しの濃色に濃色文字）を修正し、
  修正後は文字色がそれぞれ `oklch(0.24 0.03 255)`・`oklch(0.97 0.01 250)` になることを確認
- 閲覧のみユーザーの「参照のみ」バッジも、濃いヘッダー上で文字・枠線ともに `oklch(0.97 0.01 250)` になる
- 画面のボタンからセピアを選ぶ → その場でサイドバー・トップバーまで配色が変わり「設定を保存しました」が出る
- 言語を English にすると設定画面もテーマ名も英語になる
- ログアウトしてログイン画面へ行っても**テーマは維持**され、**言語の切替も残っている**
- DB: admin=ocean、viewer=dark と**ユーザーごとに別々に保存**されることを確認
- 未ログインでも `PUT /api/preferences` は 200（ログイン画面用）。知らないテーマ名は 400
- トップバーから言語の選択が消え、歯車（個人設定）に置き換わっていることを確認
- 認可の呼び忘れ検出テストが新しいAPIを検出したので、理由を書いて許可リストに追加した
- typecheck / lint / prettier / テスト81件すべて通過

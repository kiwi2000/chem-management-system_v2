# 個人設定（利用者ごとの設定）

確定日: 2026-08-14

## 「システム設定」との違い

名前が似ているので、置き場所を分けている。

| | 個人設定 `/preferences` | システム設定 `/admin/settings` |
|---|---|---|
| 誰の設定か | **その人だけ** | **全員に効く** |
| 誰が変えられるか | 本人（ログインしていれば誰でも） | システム管理者のみ |
| 中身 | 表示名・言語・テーマ・見出しの色 | 入力チェックの厳しさなど |
| API | `PUT /api/preferences` | `GET/PUT /api/settings` |

呼び方は**「個人設定」**（英語は Preferences）にした。「設定」だけだとシステム設定と紛らわしいため。

## 入口

トップバー右の**歯車アイコン**から開く。サイドバーには出さない（業務のメニューと性質が違うため）。

## 中身

### 表示名（プロフィール）
本人が変更できる。**空欄は不可**（前後の空白だけの入力も弾く）。上限200文字は管理者側のユーザー編集と揃えた。

ここだけ**保存ボタンを置く**。他の項目と違い打ち終わりが分からないため、押した時点で保存する。
空欄のときはボタンを押せなくし、説明文をその場で「表示名を入力してください」に差し替える。
サーバー側でも同じ検査をして 400 を返す（画面のチェックだけに頼らない）。

`PUT /api/preferences` は未ログインでも使えるが、**表示名だけは未ログインなら 401**。
自分のアカウントを書き換える操作のため。

### 言語
これまでトップバーにあった切替をここへ移した。**ログイン画面には残してある**（ログイン前に選べる必要があるため）。

### テーマ
14種類。選んだ瞬間に保存して画面へ反映する（保存ボタンは置かない。見た目は押した結果が見えたほうが選びやすい）。

**既定では畳んである**。種類が多く場所を取るため、畳んだ1行にも今の配色の見本を出す。
プルダウンにしなかったのは、テーマは名前ではなく色で選ぶものだから
（プルダウンだと開いて選んで閉じて確認、を繰り返すことになる）。

| テーマ | 内容 |
|---|---|
| 端末の設定に合わせる（既定） | OSが暗い配色ならダーク、そうでなければライト |
| ライト | 白を基調にした標準の配色 |
| ダーク | 黒地に金の線。罫線・枠線・フォーカス・主ボタンだけを金にして締める |
| スカイ | 明るい空色。事務作業向けのすっきりした配色 |
| オーシャン | 深い青を基調 |
| フォレスト | 緑を基調 |
| ミント | 淡い青緑。フォレストより涼しげ |
| セピア | 紙のような温かみのある配色 |
| サンセット | 温かいオレンジを基調 |
| サンフラワー | クリーム色の地に山吹色 |
| ローズ | 少し濃いピンクを基調 |
| ラベンダー | 淡い紫を基調 |
| ミッドナイト | 濃紺の暗い配色。ダークの青版 |
| 高コントラスト | 白黒をはっきりさせ、枠線を強く出す |

**黄色（サンフラワー）は面に敷かない**。黄色は明るすぎて、どの文字色でもコントラストが取れないため、
背景はクリーム色にして黄色は差し色（主ボタン・見出し）に回した。

**暗い配色は2つ**（ダーク・ミッドナイト）。`dark:` 指定が両方で効くよう、
`@custom-variant dark (&:is(.dark *, .theme-midnight *))` にしてある。

### 背景（模様・挿絵）

テーマとは独立した設定。**プルダウン**で選ぶ（名前で選べるので場所を取らせない）。

| 種類 | 選択肢 | 実装 |
|---|---|---|
| 模様 | 方眼紙 / 水玉 / 斜めストライプ / 和紙風 | CSSのグラデーションのみ。画像ファイル不要 |
| 挿絵 | ビーカー / 分子模型 / 三角フラスコ | SVGをCSSに埋め込む（data URI）。外部から取ってこない |

決めごと:

1. **色はテーマごとに持たせない**。模様の線は `color-mix(in oklab, var(--foreground) 9%, transparent)`
   ＝本文色を薄く混ぜたもの。テーマ × 背景 の組み合わせが増えないようにするため
2. **挿絵は灰色の薄い線**（`%23808080` を 35% で）。明るい配色でも暗い配色でも同じように見える
3. **表・カード・フォームの下には出さない**。数字が読みにくくなるため。
   これらは不透明な `--background` / `--card` を持っているので、敷いても上には出てこない
4. 挿絵は画面右下に貼り付け（`background-attachment: fixed`）、本文と一緒に動かさない

### 見出しをテーマの色で塗る（チェックボックス）

**テーマとは独立した入切**。テーマごとに「色付きヘッダー版」を用意すると種類が倍になり、
配色を変えずに塗るかどうかだけ変えることもできないため、独立した設定にした。

入にすると次の3か所に、**選んでいるテーマの色**を敷く。

1. 上部のバー（トップバー）
2. 表の見出し（`thead`）
3. **左ペイン上の「化学物質管理システム」の行**

仕組みは `<html>` に付く `.header-strong` クラス1つだけ。
各テーマが次の3つを持ち、`.header-strong` がそれを `--header` / `--table-head` / `--sidebar-header` へ流し込む。

| 変数 | 用途 |
|---|---|
| `--strong` | トップバーと左ペイン見出しの色 |
| `--strong-foreground` | その上に載る文字色 |
| `--strong-head` | 表の見出しの色 |

**表の見出しを計算（`color-mix`）で作らないのは、明暗どちらへずらすべきかが配色で違うため**。
濃い色（オーシャン・ダーク等）は明るい側へ、明るい色（スカイ・サンセット）は暗い側へずらさないと文字が読めなくなる。

**明るい配色は文字を濃色にしている**（スカイ＝濃紺、サンセット＝濃茶）。
「濃くする」ではなく「色で塗る」設定なので、色に応じて文字側を反転させるほうが読みやすい。

**既定（切）では `--header` は `var(--background)`・`--table-head` は `transparent`・
`--sidebar-header` は `var(--sidebar)`** なので、切のときの見た目は従来とまったく同じになる。

色を敷くと、中の要素が読めなくなるものがあるので次のようにしてある。

- 表の `th` は既定で `text-foreground` を持つため、`[&_th]:text-inherit` で打ち消して見出しの文字色を継承させる
- 背景を持つボタン（ログアウトなど）は文字色を `text-foreground` に固定する。継承すると白地に白文字になる
- 枠線だけのバッジ（「参照のみ」）は `border-current text-inherit` にして継承させる
- 並べ替えの見出しボタンは、色を変えるのではなく `hover:opacity-75` で反応させる

## 動作の決めごと

1. 保存先は **Cookie ＋ ログイン中なら本人の設定**
   （`users.preferred_locale` / `preferred_theme` / `preferred_header_strong` / `preferred_background`）。言語と同じ形
2. 優先順位は **Cookie → 本人の設定 → 既定**
3. テーマは**サーバー側で決めてから描画**する。開いた直後に色が入れ替わるちらつきが起きない
4. 「端末の設定に合わせる」のときだけ、描画前に走る小さなスクリプトで OS の設定を見て `.dark` を付ける
5. `PUT /api/preferences` は**表示名以外は認証不要**（ログイン画面で言語やテーマを選べる必要があるため）。
   副作用は Cookie と本人の設定だけで、業務データには触れない
6. 知らないテーマ名・言語コード・空の表示名は 400 で弾く

内部の名前は `header-strong` / `chem_header_strong` / `preferred_header_strong` のまま。
画面の言い回しだけを変えており、意味（見出しを強調する）は変わらないため。

## テーマの足し方

1. `apps/web/app/globals.css` に `.theme-<名前>` を足し、色の変数を上書きする。
   **`--strong` / `--strong-foreground` / `--strong-head`（見出しを塗るときの色）も必ず書く**
2. `packages/shared/src/theme.ts` の `THEMES` と `THEME_SWATCHES` と `THEME_STRONG_SWATCH` に足す
3. `packages/shared/src/i18n/ja.ts` の `preferences.themes` / `themeDescriptions` に名前と説明を書き、`en.ts` にも入れる

### 背景の実測

- 7種類すべてで `body` の `background-image` が入る（なし → `none`）
- 模様の色はテーマに追随する（セピアで測ると `oklab(0.29 0.015 … / 0.09)` ＝本文色の9%）
- 挿絵3種の SVG は**画像として読み込み成功**（150×150）。`background-size: 320px`・右下から40px
- 知らない値（`unicorn`）を送ると 400
- ミッドナイト＋分子模型＋色付きヘッダーで、表の外枠は不透明な `oklch(0.18 0.025 265)` のまま
  ＝**模様が表の下に透けない**
- ミッドナイトでも `dark:` 指定が効く（状態アイコンの緑が `#05df72` ＝暗い配色用の色）

- ログアウトボタンは色付きヘッダー上でも文字 `oklch(0.145 0 0)` / 背景 `oklch(1 0 0)` で読める
- Cookie は `chem_header_strong=1` / `=0`。DB は `users.preferred_header_strong` に `t` / `f` で入る
- `headerStrong` に真偽値以外を送ると 400。廃止した `navy` を送っても 400
- 廃止した4テーマを選んでいた人は、マイグレーションで近い配色＋入 に読み替えた
  （実測: viewer は `navy` → `sky` ＋ `preferred_header_strong = t`）
- 英語表示でも「Colour the headings」と説明が出る

# S31 付録: 製品の公開先・利用者の所属・権限の関係（整理表）

2026-10-21。「製品・原材料の持ち主、利用者の所属する組織、利用者の権限が密接に絡んで複雑なので、関係を整理する表を」（利用者）。
S31 本文の考え方を、この表だけ見れば分かる形に書き直したもの。ここで決め直したことは本文に反映する。

## 0. 言葉

| 言葉 | 意味 |
| --- | --- |
| 組織 | 階層のあるグループ。親は 1 つ、深さは自由。種別（会社・部署・取引先・その他）は呼び名で、階層の意味は無い |
| トップ | その枝のいちばん上の組織（親の無い組織）。会社が複数あれば、トップも複数 |
| 所属 | 利用者がどの組織に属するか。複数可。1 つを「主な所属」にする |
| 公開先（持ち主） | 製品・原材料ごとに 1 つ。「全体で共通」か、組織を 1 つ。組成・添付・判定・帳票はその製品の公開先に従う |
| 操作の権限 | 製品を見られる／編集できる、組成を見られる、法規制を…など 24 種類。人にも組織にも付けられる |
| 範囲の付与 | ある組織に「別の組織（とその下）の製品を見られる／直せる」を付けるもの。化学物質管理の部署向け |
| 管理者 | ADMIN。人にも組織にも付けられる。見える範囲は全部 |

## 1. 利用者から見て、製品 1 つが「見える」「直せる」か

製品の公開先と、利用者の所属する組織の位置関係で決まる。**見るには「製品を見られる」権限、直すには「製品を編集できる」権限が別に要る**（権限が無ければ位置に関わらず ×）。

| 製品の公開先 ＼ 利用者の所属 | 同じ組織 | その上の組織（先祖） | その下の組織（子孫） | 別の枝（横） | 範囲の付与「見る」を受けた組織 | 範囲の付与「直す」を受けた組織 | 管理者 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 全体で共通 | 見る○ 直す○ | 見る○ 直す○ | 見る○ 直す○ | 見る○ 直す○ | 見る○ 直す○ | 見る○ 直す○ | 見る○ 直す○ |
| 組織 X（トップ） | 見る○ 直す○ | （無い） | 見る○ 直す○ | 見る× 直す× | 見る○ 直す× | 見る○ 直す○ | 見る○ 直す○ |
| 組織 X（途中・末端） | 見る○ 直す○ | 見る○ 直す○ | 見る○ 直す○ | 見る× 直す× | 見る○ 直す× | 見る○ 直す○ | 見る○ 直す○ |

- 「同じ縦の線上にいる人は全員見える」が芯。上の人は下の製品を見られ、下の人は上に公開された製品を見られる。横の枝だけが見えない
- 「全体で共通」は組織に関係なく全員。既存の製品はすべてこれ（入れた日に見え方が変わらない）
- 「直す」は、見える範囲の中で「製品を編集できる」権限があるとき。範囲の付与「見る」だけの組織は直せない
- 公開状態（公開済／作成中／承認待ち）と有効／無効の条件は、これとは別に従来どおり効く（未公開のものは「未公開も見られる」権限か、作った本人だけ）。**両方を満たしたときだけ見える**
- 作った本人は、公開先が自分の範囲の外に付け替えられても見え続ける（推奨。未決 §6-2）

## 2. 操作の権限は、どこから来るか

| 出どころ | 効くか | 備考 |
| --- | --- | --- |
| 本人に付けた権限 | ○ | いままでどおり。例外の調整はここで |
| 所属する組織に付けた権限 | ○ | 異動したら所属を変えるだけで付け替わる |
| 所属する組織の上（先祖）に付けた権限 | ○ | 上で付けた権限は下へ効く |
| 所属する組織の下（子孫）に付けた権限 | × | 下で付けたものは上へは効かない |
| 別の枝の組織に付けた権限 | × | |
| 無効にした組織（とその下）に付けた権限 | × | 親を無効にしたら下も無効扱い。本人の権限は残る |
| 「禁止」 | （無い） | 禁止の設定は無い。どれか 1 つで許可されていれば許可。だから上下で矛盾しない |

複数の組織に所属していれば、全部の足し合わせ。管理者の権限も同じ（「管理者」という組織を作れる）。

## 3. 見える範囲は、どこから来るか

| 出どころ | 見る | 直す | 備考 |
| --- | --- | --- | --- |
| 所属する組織と、その上下の線上（§1） | ○ | ○（権限があれば） | |
| 所属する組織（またはその上）が受けた範囲の付与「見る」 | ○ | × | 付与の対象の組織とその下 |
| 所属する組織（またはその上）が受けた範囲の付与「直す」 | ○ | ○ | 同上 |
| 付与を受けた組織が、さらに受けている付与 | × | × | 連鎖しない（A→B→C で A は C を見られない） |
| 管理者 | 全部 | 全部 | |

## 4. 製品・原材料を作るときの公開先の既定

| 設定（システム設定。製品と原材料で別々） | 作るときの既定 | 手で変えられる先 |
| --- | --- | --- |
| 全体で共通 | 全体で共通 | 自分の線上の組織（主な所属のトップ〜主な所属〜その下）のどれか |
| 組織内のみ | **主な所属のトップ** | 同上。トップより下の組織に限定するときは手で選ぶ |

- 製品と原材料の区別は「原材料として使える」の印（`usableAsMaterial`）で見る
- あとから公開先を変えるときは、元の公開先と新しい公開先の**両方**が自分の「直せる範囲」にあること（自分の範囲の外へ押し出す・外から引き込むを防ぐ）
- 既存の製品はすべて「全体で共通」。必要なものから手で変える

## 5. 原材料と組成の見え方

| 場面 | 動き |
| --- | --- |
| 製品の組成に、見えない原材料（別の枝に公開）が入っている | その原材料は「開けない原材料」になり、合算と判定は不完全（要判断の印）。組成の中身は出ない |
| 原材料が「全体で共通」 | 誰の製品からも開ける。組成の中身は「組成を見られる」権限で決まる（いままでどおり） |
| 原材料がトップに公開 | 同じ会社の全員から開ける。別の会社（別のトップ）からは開けない |
| 組成の中身を見る | 製品が見える ＋「組成を見られる」権限。公開先の範囲は製品と同じ |
| 添付ファイル・帳票・判定 | 製品に従う（製品が見えなければ出ない） |

部署をまたいで使う原材料は「全体で共通」にするのが素直。会社内だけなら「トップ」。

## 6. 例（この木で確かめる）

```
A社（トップ）
├─ 営業部
│   ├─ 営業1課
│   └─ 営業2課
└─ 技術部
    └─ 化学物質管理課   ← 範囲の付与「全部を見る」
B社（トップ）
```

利用者（全員「製品を見られる」「製品を編集できる」を持つとする）

| 利用者 | 所属 |
| --- | --- |
| 甲 | 営業1課 |
| 乙 | 営業部 |
| 丙 | 技術部 |
| 丁 | 化学物質管理課 |
| 戊 | B社 |
| 己 | 管理者（組織「管理者」に所属） |

製品

| 製品 | 公開先 |
| --- | --- |
| P1 | 全体で共通 |
| P2 | A社（トップ） |
| P3 | 営業部 |
| P4 | 営業1課 |
| P5 | 営業2課 |
| P6 | B社 |

誰に何が見える・直せる（○ 見る＋直す、△ 見るだけ、× 見えない）

| | P1 共通 | P2 A社 | P3 営業部 | P4 営業1課 | P5 営業2課 | P6 B社 |
| --- | --- | --- | --- | --- | --- | --- |
| 甲（営業1課） | ○ | ○ | ○ | ○ | × | × |
| 乙（営業部） | ○ | ○ | ○ | ○ | ○ | × |
| 丙（技術部） | ○ | ○ | × | × | × | × |
| 丁（化学物質管理課、全部を見る） | ○ | ○ | △ | △ | △ | △ |
| 戊（B社） | ○ | × | × | × | × | ○ |
| 己（管理者） | ○ | ○ | ○ | ○ | ○ | ○ |

読み方

- 甲は自分の線上（A社・営業部・営業1課）の製品が見える。横の営業2課（P5）は見えない
- 乙は営業部の下（営業1課・営業2課）も見える。技術部の製品があれば見えない
- 丁は範囲の付与で全部見えるが、直せるのは自分の線上（P1・P2）だけ。付与を「直す」にすれば全部直せる
- 戊は別のトップなので、A社の製品は共通の P1 しか見えない
- 丁が営業部に異動したら、所属を変えるだけで乙と同じ見え方になる（権限と範囲は組織に付いているため）

## 7. 決め残っていること（S31 本文 §6）

1. ~~部署をまたいで使う原材料~~ → 2026-10-21 決定: 「全体で共通」を選べる。既定はシステム設定（製品・原材料で別）
2. 作った本人は、公開先が範囲の外に変わっても見え続けるか（推奨: 見え続ける）
3. 帳票の差出人は従来どおり「種別で絞って表示順の先頭」か、「主な所属」か（推奨: 従来どおり）
4. PRTR の入力を、上の組織の人が下の組織の分も入れられるようにするか（推奨: 入れられる）
5. お知らせのグループを組織に移すときの種別（推奨: その他、呼び名「お知らせ」）

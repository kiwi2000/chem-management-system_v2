# CHRIP の取り込み — 決めていないこと

2026-08-29 時点、2026-08-31 追記。CHRIP から CAS リンクを作る作業のうち、
**判断が要るために保留にしているもの**を1つにまとめる。

**取得は 2026-08-31 に完了（23,353件）。同日、ローカルと本番の両方へ取り込み済み**
（物質 +24件、CASリンク +44,281件）。**詳細ページは物質のすべての情報源を含むので、
ここに挙げた保留は後から決めても取り直しは要らない。**対応表に足して取り込みを流し直すだけで済む。

## 1. 本システムに区分が無いもの

CHRIP はこちらが選んだ法律について、**本システムが持っていない区分**も返す。
いまは取り込まずに捨てている。区分を足せば使えるようになる。

### 1-1. 大気汚染防止法（該当 9,144件）

本システムの区分は **有害物質（5件）／特定粉じん（1件）** のみ。CHRIP が返すのは主に次の2つ。

| CHRIP の分類 | 政令番号の例 | 政令名称の例 |
|---|---|---|
| 揮発性有機化合物（ＶＯＣ） | `法第2条第4項` | 大気中に排出され、又は飛散した時に気体である有機化合物… |
| 有害大気汚染物質に該当する可能性がある物質 | `中環審第9次答申(別表1)の150` | ｏ－ニトロアニリン |

- **VOC** は物質を個別に指定するものではなく、条文の定義に当たるかどうか。政令名称も定義文そのもの
- **有害大気汚染物質に該当する可能性がある物質**は中央環境審議会の答申（別表1）で、法令の別表ではない

**2026-09-01 決着。区分を2つ作って登録した**（第8章 8-5b）。
LOLI の一覧 `3074` から、別表1を228件・別表2（優先取組物質）を23件、日本語つきで入れた。

**VOC も 2026-09-02 に決着。**条文の定義文を法文物質名1件として持ち、そこに589件のCASを
ぶら下げた（第8章 8-8f）。判定には使い、当たれば必ず要確認にする。
定義から除かれる8物質（令第2条の2）は別の区分にして、判定には使わない。
**判定には使わない設定**（区分の `judged` を false）。以下は判断の材料として残す。

CHRIP 側は「分類」として区分している。23,353件ぶんの実データでの内訳は次のとおり。

| CHRIP の分類 | 件数 | 政令番号の形 |
|---|---|---|
| 有害大気汚染物質に該当する可能性がある物質 | 6,167 | `中環審第9次答申(別表1)のN` |
| 同（**優先取組物質**） | 2,184 | `中環審第9次答申(別表2)のN` |
| 揮発性有機化合物（ＶＯＣ） | 576 | `法第2条第4項`（定義文そのもの） |
| ばい煙（有害物質） | 121 | `政令第1条第N号` |
| 特定物質 | 28 | `政令第10条第N号` |
| 自動車排出ガス・特定粉じん・ほか | 40 | — |

- **別表1と別表2は CHRIP でも別の分類。**足すなら区分は2つになる
- **振り分けに「分類」の文字は要らない。**政令番号に `別表1` / `別表2` が入っているので、番号だけで分けられる
- 足した結果、CHRIP の当たらずは **11,921件 → 3,629件** になった

**判定に使うかは別の判断。**中環審の答申は「該当する可能性がある物質」の候補一覧であって、
含有率で該非が決まる規制ではない。判定に出すと、ほとんどの製品で「該当」が並ぶ。

### 1-1-2. 法律の箱の切り分けが、ときどきずれる（実害は無し）

詳細ページを法律ごとの箱に切り分けるとき、`scripts/lib/chrip-detail.mjs` の `SOURCE_HEAD` が
知らない法律（**高圧ガス保安法・火薬類取締法・麻薬向精神薬原料**）の箱は、**直前の箱に吸い込まれる**。
実データで **113件**。

| | 件数 | 中身 |
|---|---|---|
| 分類の文字だけがずれた | 89 | 番号と名前はその法律自身のもの。**リンクは正しい** |
| 番号ごとよその法律 | 24 | 例 `政令第10条第4号 一酸化炭素`（高圧ガス保安法）。当たらず、**リンクは作られていない** |

**取り込みは「番号」と「名前」で当てており、「分類」は見ていないので、誤ったリンクは入っていない**
（2026-08-31 に書き込み済みの 44,281件を突き合わせて確認）。
**分類の文字を使う場面が出たら、先に `SOURCE_HEAD` を直すこと。**

### 1-2. 水質汚濁防止法（該当 6,969件）

本システムの区分は **有害物質（28件）／指定物質（60件）**。CHRIP は次を返す。

| CHRIP の分類 | 政令番号の例 | 政令名称の例 | 本システム |
|---|---|---|---|
| 有害物質 | `政令第2条第17号` | １，１，２－トリクロロエタン | **あり**（取り込める） |
| 生活環境項目 | `政令第3条第5号` | フエノール類含有量 | **無し** |
| 生活環境項目 | `政令第3条第12号` | 窒素又は燐の含有量… | **無し** |

「生活環境項目」は排水基準の項目（フェノール類含有量、窒素・りん）で、物質の指定ではなく**測定項目**。

**2026-09-01 決着。区分を作って登録した**（第8章 8-5c）。
「水素イオン濃度等の項目」として令第3条から60件。**判定には使わない設定**にしてある
（物質の指定ではなく測定項目なので、含有率で該非が決まらない）。

### 1-3. 毒劇法（該当 2,713件）

本システムの区分は **毒物（134）／劇物（434）／特定毒物（20）** で、いずれも**法別表**（法律で指定されたもの）。
CHRIP は法別表のほかに**政令で指定された製剤**を返す。

| CHRIP の分類 | 政令番号の例 | 政令名称の例 |
|---|---|---|
| 法律・劇物 | `法律別表第2の15` | （法別表のもの。**取り込める**） |
| 政令・劇物 | `政令第2条第1項第25号` | クレゾールを含有する製剤。ただし、クレゾール５％以下を含有するものを除く。 |
| 政令・毒物 | `政令第2条第1項…` | （同上） |

政令指定の製剤には**除外条件（〜％以下を除く）**が書かれている。

**2026-09-02 決着。もともと入っていた。**政令で指定された製剤は CHRIP からではなく、
**毒物及び劇物指定令（一次資料）から**取り込んである（毒物134件中106件、劇物434件中340件、
特定毒物20件中10件が指定令のもの）。足すかどうかを決める話ではなかった。

**代わりに直したこと。**除外の割合が備考に文章として置かれているだけで、判定は
「0を超えれば該当」のままだった。**144件の割合を閾値の下限に入れた**
（`docs/法規制データの作り方.md` 第8章 8-3）。

**2番目の TSCA も決着**（後述 2-1）。**3番目の韓国も決着**（後述 2-2）。

## 2. どの法律に当てるか決めていないもの

### 2-1. TSCA（該当 266件）

| | |
|---|---|
| CHRIP の情報源 | TSCA：化学物質及び混合物の優先度付け、リスク評価並びに規制 |
| いまの対応表 | 有害物質規制法（TSCA）／第6条 規制物質 |

第6条は規制の条文なので近いが、CHRIP 側は「優先度付け・リスク評価」も含む名前になっている。
**リスク評価の対象になっただけの物質**まで「第6条 規制物質」として入る恐れがあった。

**2026-09-02 決着。この対応でよい。**CHRIP は詳細ページに **CFR番号**を持っており、
266件すべてを数えたところ、**全件が実際に規制されている条を指していた**。

| CFR番号 | 件数 | 中身 |
|---|---:|---|
| 40 CFR 761 | 235 | PCB |
| 40 CFR 749.68 | 11 | 六価クロム系水処理剤 |
| 40 CFR 763 | 8 | アスベスト |
| 40 CFR 747.xxx | 5 | 金属加工油ほか |
| 40 CFR 751.4xx | 5 | メチレンクロライド等 |
| （番号なし） | 1 | — |

いずれも TSCA 第6条に基づく規則。**リスク評価の対象になっただけのものは1件も無い。**
情報源の名前が広いだけだった。

### 2-2. 韓国（該当 2,833件）

| | |
|---|---|
| CHRIP の情報源 | 韓国：化評法( K-REACH)／化管法：有害化学物質、重点管理物質 |
| いまの対応表 | K-REACH（禁止物質／制限物質／重点管理物質） |

CHRIP の1項目が、韓国の **2つの法律**（化評法＝K-REACH と 化管法）にまたがっている。
本システムはこの2つを別の法律として持つ。

- 化学物質の登録及び評価等に関する法律（K-REACH）… 禁止物質／制限物質／重点管理物質
- 化学物質管理法（KR-CCA）… 事故備え物質

**2026-09-02 に分かったこと。**詳細ページの**カテゴリ**で見分けられる。
「どちらに入れるか」ではなく、**カテゴリごとに行き先が分かれる**。

| CHRIP のカテゴリ | 行き先 | 受け皿 |
|---|---|---|
| Prohibited Substances | K-REACH 禁止物質 | **あり** |
| Restricted Substances | K-REACH 制限物質 | **あり** |
| Substances subject to intensive control | K-REACH 重点管理物質 | **あり** |
| Substances requiring preparation for accidents | 化管法 事故備え物質 | **あり** |
| **Toxic Substances** | **化管法 毒性物質** | **無し。作る必要があった** |

**2026-09-02 決着。3つの区分を新設した。**

毒性物質（유독물질）は、**有害性の種類ごとに閾値が違う。**
`Acutely:1%, Chronically:0.3%, Environment:25%` のように、1つの号に3つの値が並ぶ。
1つの区分にまとめると閾値を1つしか持てないので、**種類ごとに3つに分けた。**

| 頭に付く語 | 区分コード | 区分名 |
|---|---|---|
| `Acutely:` | `TOXIC_ACUTE` | 急性毒性物質（人の健康） |
| `Chronically:` | `TOXIC_CHRONIC` | 慢性毒性物質（人の健康） |
| `Environment:` | `TOXIC_ECO` | 生態毒性物質 |

これで**閾値を号ごとに正しく持てる。**0-2b の「いちばん広く当たる値を採る」は、
同じ区分の中に値が2つ以上あるときの決めごとで、種類の違いを潰すためのものではない。

**両方のデータソースから、それぞれ単独で作れる**（第0章 0-2）。

| | 出どころ | 号 |
|---|---|---|
| CHRIP | 詳細ページのカテゴリと「対象となる範囲（％）」の頭に付く語 | 992 / 247 / 675 |
| LOLI | 一覧 10266 / 10267 / 10268（`refno`） | 992 / 247 / 675 |

**互いを見ずに作って、号の数が3つとも一致した。**（一致は後から確かめただけで、
取り込みの判断には使っていない）

**区分を置いた法律は化管法（`KR-CCA`）。**毒性物質を指定するのは化管法
（環境部長官の指定告示）。禁止物質・制限物質は化評法（K-REACH）第27条の指定で、
化管法はそれを引いているだけなので、**そちらは K-REACH のままでよい。**
詳しくは `docs/法規制データの作り方.md` 第8章 8-8g。

## 4. 番号が突き合わせられないもの

本システムの `officialNumber` と CHRIP の政令番号は、法律ごとに書き方が違う。
言い換えで届くものと、届かないものがある。

| 法律 | CHRIP | 本システム | 対応 |
|---|---|---|---|
| 安衛法 表示・通知 | `規則別表第2の1486` | `則別表第2の1486` | 言い換えで届く |
| 毒劇法（法別表） | `法律別表第2の15` | `法別表第2の15` | 言い換えで届く |
| 水質・土壌 | `政令第3条第5号` | `令第3条第5号` | 言い換えで届く |
| 化管法 | `1-86` | `令別表第1の86` | 組み立て直しで届く |
| 安衛法 有機則 | `12` | `令別表第6の2の28` | **届かない**（名前で当てる） |
| 大気汚染防止法 | `中環審第9次答申(別表1)の150` | `令第…条…` | **届かない**（体系が違う） |

番号で当たらないものは**法律で絞ってから名前**で当てる。手元の実データでは、
本システムが持つ区分に限れば 11/11 当たっている。

## 5. 後から足すときの手順

1. `scripts/chrip-import.ts` の `LAW_OF` に情報源を足す（区分は書かない。番号と名前が決める）
2. 区分が足りなければ、画面の「法規制 → 法律 → ＋区分」で足す
3. `node --env-file=.env node_modules/tsx/dist/cli.mjs --tsconfig apps/web/tsconfig.json scripts/chrip-import.ts` で下見
4. 件数を確かめてから `--write`

**取り込みは足すだけ**なので、何度流しても既にあるものは触らない。

追加の取得が要るのは「その法規制**だけ**に該当する物質」のみ。

| 対象 | 追加取得 | 時間 |
|---|---|---|
| 大気・水質・土壌だけに該当 | 752件 | 約1.4時間 |
| TSCA・韓国だけに該当 | 775件 | 約1.4時間 |

それ以外は、すでに取得した詳細ページの中に情報が入っている。

## 6. 2026-08-29 に分かったこと（詳細2,627件を読んだ時点）

### 直したもの

| 直したところ | 中身 | 効き目 |
|---|---|---|
| 情報源の名前 | 現行の化管法は CHRIP では「化管法SDS制度 作成・提供方法（経産省）」で載る。対応表が古い名前のままで、**化管法のリンクが1件も取れていなかった** | 化管法 1,273物質ぶんが取れるようになった |
| 政令番号の0埋め | 化管法は「1-045」のように0で埋めて書かれることがある。本システムは「令別表第1の45」 | 同上 |
| 安衛法の番号の書きかた | 「政令第17条別表第3第1号の3」「別表第3第1号3」「別表第3第2号23の3」の3通りを寄せた | 取りこぼし 96件 → 13件 |

この3つで、同じデータ量でのCASリンクが 3,272件 → 5,274件になった。

### まだ取り込んでいない情報源

CHRIP は25種類の情報源を持っている。うち本システムに無いものは次のとおり。
**製品の判定に使えるかどうかで分けた。**

| 情報源 | 物質数 | 判定に使えるか |
|---|---|---|
| 特定物質等の規制等によるオゾン層の保護に関する法律 | 8 | **使える。**日本のオゾン層保護法。本システムに法律ごと無い。モントリオール議定書の国内版にあたる |
| 安衛法：皮膚等障害化学物質等（不浸透性の保護具の使用義務） | 338 | **使える。**令和6年4月から義務。ただしCHRIPは適用日しか持たず、政令番号が無い |
| 安衛法：がん原性物質（作業記録30年保存） | 38 | **使える。**同じく政令番号が無い |
| 安衛法：鉛等／四アルキル鉛等 | 9 | **使える。**鉛則・四アルキル鉛則 |
| 安衛法：危険物 | 84 | **使えない。**引火点などの物理的性質で決まる分類。含有率では判定できない |
| 安衛法：濃度基準値設定物質 | 33 | **使えない。**作業環境の濃度であって、製品の含有率ではない |
| 安衛法：強い変異原性が認められた化学物質 | 30 | 有害性の分類。IARC と同じ理由で除外 |
| 安衛法官報公示時期 | 61 | 公示の時期であって規制ではない |
| 化管法（令和４年度分まで） | 1,150 | 現行版に置き換わった古い一覧 |
| 毒物及び劇物取締法：有機シアン化合物から除かれるもの | 10 | **除外の一覧。**そのまま入れると逆の意味になる。取り込むなら「除外」として扱う |
| 韓国：化評法(K-REACH)：その他 | 106 | 中身の確認がまだ |

政令番号を持たない情報源（皮膚等障害・がん原性物質）は、
**法文物質名をCASそのもので作る**ことになる。条約と同じやりかたで作れるが、
法令の言葉ではないので、区分の備考にその旨を書く必要がある。

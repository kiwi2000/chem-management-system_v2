# CHRIP の取り込み — 決めていないこと

2026-08-29 時点。CHRIP から CAS リンクを作る作業のうち、**判断が要るために保留にしているもの**を1つにまとめる。

取得そのものは進行中（23,353件の詳細を取得中）。**詳細ページは物質のすべての情報源を含むので、ここに挙げた保留は後から決めても取り直しは要らない。**対応表に足して取り込みを流し直すだけで済む。

---

## 前提

| 項目 | 値 |
|---|---|
| 対象バージョン | 2026Q3 |
| データソース | CHRIP（2026Q3 での優先度は 3 番目。1=USER、2=LOLI） |
| CHRIP の全物質 | 306,677 |
| 23法規制のいずれかに該当 | 23,353（7.6%） |

取り込みの流れは `法文物質名 ↔ CAS` の対応を作ること。CHRIP の詳細ページから
**政令番号**と**政令名称**を取り、本システムの `officialNumber` と名称に突き合わせる。

---

## 1. 本システムに区分が無いもの

CHRIP はこちらが選んだ法律について、**本システムが持っていない区分**も返す。
いまは取り込まずに捨てている。区分を足せば使えるようになる。

### 1-1. 大気汚染防止法（該当 9,144件）

本システムの区分は **有害物質（5件）／特定粉じん（1件）** のみ。CHRIP が返すのは主に次の2つ。

| CHRIP の分類 | 政令番号の例 | 政令名称の例 |
|---|---|---|
| 揮発性有機化合物（ＶＯＣ） | `法第2条第4項` | 大気中に排出され、又は飛散した時に気体である有機化合物… |
| 有害大気汚染物質に該当する可能性がある物質 | `中環審第9次答申(別表1)の150` | ｏ－ニトロアニリン |

- **VOC** は物質を個別に指定するものではなく、条文の定義に当たるかどうか。政令名称も定義文そのもの
- **有害大気汚染物質に該当する可能性がある物質**は中央環境審議会の答申（別表1）で、法令の別表ではない

**決めること**：この2つを区分として足すか。足すなら判定に使うのか（VOC は含有率で該非を出す性質ではない可能性がある）。

### 1-2. 水質汚濁防止法（該当 6,969件）

本システムの区分は **有害物質（28件）／指定物質（60件）**。CHRIP は次を返す。

| CHRIP の分類 | 政令番号の例 | 政令名称の例 | 本システム |
|---|---|---|---|
| 有害物質 | `政令第2条第17号` | １，１，２－トリクロロエタン | **あり**（取り込める） |
| 生活環境項目 | `政令第3条第5号` | フエノール類含有量 | **無し** |
| 生活環境項目 | `政令第3条第12号` | 窒素又は燐の含有量… | **無し** |

「生活環境項目」は排水基準の項目（フェノール類含有量、窒素・りん）で、物質の指定ではなく**測定項目**。

**決めること**：生活環境項目を区分として足すか。

### 1-3. 毒劇法（該当 2,713件）

本システムの区分は **毒物（134）／劇物（434）／特定毒物（20）** で、いずれも**法別表**（法律で指定されたもの）。
CHRIP は法別表のほかに**政令で指定された製剤**を返す。

| CHRIP の分類 | 政令番号の例 | 政令名称の例 |
|---|---|---|
| 法律・劇物 | `法律別表第2の15` | （法別表のもの。**取り込める**） |
| 政令・劇物 | `政令第2条第1項第25号` | クレゾールを含有する製剤。ただし、クレゾール５％以下を含有するものを除く。 |
| 政令・毒物 | `政令第2条第1項…` | （同上） |

政令指定の製剤には**除外条件（〜％以下を除く）**が書かれている。本システムの
「条件つきの除外」の扱いに乗せられる可能性がある。

**決めること**：政令指定の製剤を、毒物・劇物の区分に足すか、別の区分にするか。

## 2. どの法律に当てるか決めていないもの

### 2-1. TSCA（該当 266件）

| | |
|---|---|
| CHRIP の情報源 | TSCA：化学物質及び混合物の優先度付け、リスク評価並びに規制 |
| いまの対応表 | 有害物質規制法（TSCA）／第6条 規制物質 |

第6条は規制の条文なので近いが、CHRIP 側は「優先度付け・リスク評価」も含む名前になっている。
**リスク評価の対象になっただけの物質**まで「第6条 規制物質」として入る恐れがある。

**決めること**：この対応でよいか。中身（詳細ページ）を数件見てから決めるのが安全。

### 2-2. 韓国（該当 2,833件）

| | |
|---|---|
| CHRIP の情報源 | 韓国：化評法( K-REACH)／化管法：有害化学物質、重点管理物質 |
| いまの対応表 | K-REACH（禁止物質／制限物質／重点管理物質） |

CHRIP の1項目が、韓国の **2つの法律**（化評法＝K-REACH と 化管法）にまたがっている。
本システムはこの2つを別の法律として持つ。

- 化学物質の登録及び評価等に関する法律（K-REACH）… 禁止物質／制限物質／重点管理物質
- 化学物質管理法（KR-CCA）… 事故備え物質

**決めること**：どちらに入れるか。詳細ページの分類欄で見分けられるかを確かめる必要がある。

## 3. 使えないもの

### 3-1. 韓国：化評法( K-REACH)：その他（該当 938件）

詳細ページに**注記しか入っていない**。

```
注記: The registration grace period is until June 30 …
```

法文物質名も番号も無いため、**CAS リンクを作れない**。対応表から外している。

---

## 4. 番号が突き合わせられないもの

本システムの `officialNumber` と CHRIP の政令番号は、法律ごとに書き方が違う。
言い換えで届くものと、届かないものがある。

| 法律 | CHRIP | 本システム | 対応 |
|---|---|---|---|
| 安衛法 表示・通知 | `規則別表第2の1486` | `則別表第2の1486` | 言い換えで届く |
| 毒劇法（法別表） | `法律別表第2の15` | `法別表第2の15` | 言い換えで届く |
| 水質・土壌 | `政令第3条第5号` | `令第3条第5号` | 言い換えで届く |
| 化管法 | `1-86` | `令別表第1の86` | 組み立て直しで届く |
| 安衛法 有機則 | `12` | `令別表第6の2の28` | **届かない**（名前で当てる） |
| 大気汚染防止法 | `中環審第9次答申(別表1)の150` | `令第…条…` | **届かない**（体系が違う） |

番号で当たらないものは**法律で絞ってから名前**で当てる。手元の実データでは、
本システムが持つ区分に限れば 11/11 当たっている。

## 5. 後から足すときの手順

1. `scripts/chrip-import.ts` の `LAW_OF` に情報源を足す（区分は書かない。番号と名前が決める）
2. 区分が足りなければ、画面の「法規制 → 法律 → ＋区分」で足す
3. `node --env-file=.env node_modules/tsx/dist/cli.mjs --tsconfig apps/web/tsconfig.json scripts/chrip-import.ts` で下見
4. 件数を確かめてから `--write`

**取り込みは足すだけ**なので、何度流しても既にあるものは触らない。

追加の取得が要るのは「その法規制**だけ**に該当する物質」のみ。

| 対象 | 追加取得 | 時間 |
|---|---|---|
| 大気・水質・土壌だけに該当 | 752件 | 約1.4時間 |
| TSCA・韓国だけに該当 | 775件 | 約1.4時間 |

それ以外は、すでに取得した詳細ページの中に情報が入っている。

## 6. 2026-08-29 に分かったこと（詳細2,627件を読んだ時点）

### 直したもの

| 直したところ | 中身 | 効き目 |
|---|---|---|
| 情報源の名前 | 現行の化管法は CHRIP では「化管法SDS制度 作成・提供方法（経産省）」で載る。対応表が古い名前のままで、**化管法のリンクが1件も取れていなかった** | 化管法 1,273物質ぶんが取れるようになった |
| 政令番号の0埋め | 化管法は「1-045」のように0で埋めて書かれることがある。本システムは「令別表第1の45」 | 同上 |
| 安衛法の番号の書きかた | 「政令第17条別表第3第1号の3」「別表第3第1号3」「別表第3第2号23の3」の3通りを寄せた | 取りこぼし 96件 → 13件 |

この3つで、同じデータ量でのCASリンクが 3,272件 → 5,274件になった。

### まだ取り込んでいない情報源

CHRIP は25種類の情報源を持っている。うち本システムに無いものは次のとおり。
**製品の判定に使えるかどうかで分けた。**

| 情報源 | 物質数 | 判定に使えるか |
|---|---|---|
| 特定物質等の規制等によるオゾン層の保護に関する法律 | 8 | **使える。**日本のオゾン層保護法。本システムに法律ごと無い。モントリオール議定書の国内版にあたる |
| 安衛法：皮膚等障害化学物質等（不浸透性の保護具の使用義務） | 338 | **使える。**令和6年4月から義務。ただしCHRIPは適用日しか持たず、政令番号が無い |
| 安衛法：がん原性物質（作業記録30年保存） | 38 | **使える。**同じく政令番号が無い |
| 安衛法：鉛等／四アルキル鉛等 | 9 | **使える。**鉛則・四アルキル鉛則 |
| 安衛法：危険物 | 84 | **使えない。**引火点などの物理的性質で決まる分類。含有率では判定できない |
| 安衛法：濃度基準値設定物質 | 33 | **使えない。**作業環境の濃度であって、製品の含有率ではない |
| 安衛法：強い変異原性が認められた化学物質 | 30 | 有害性の分類。IARC と同じ理由で除外 |
| 安衛法官報公示時期 | 61 | 公示の時期であって規制ではない |
| 化管法（令和４年度分まで） | 1,150 | 現行版に置き換わった古い一覧 |
| 毒物及び劇物取締法：有機シアン化合物から除かれるもの | 10 | **除外の一覧。**そのまま入れると逆の意味になる。取り込むなら「除外」として扱う |
| 韓国：化評法(K-REACH)：その他 | 106 | 中身の確認がまだ |

政令番号を持たない情報源（皮膚等障害・がん原性物質）は、
**法文物質名をCASそのもので作る**ことになる。条約と同じやりかたで作れるが、
法令の言葉ではないので、区分の備考にその旨を書く必要がある。

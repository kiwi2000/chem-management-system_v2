# LOLI取り込み記録（各国インベントリ）

外部データベース LOLI から、各国のインベントリ（既存化学物質名簿）を取り込んだ記録。
**何をどこから取り、番号がどう入っているか**を残すためのもの。

| | |
| --- | --- |
| 取り込み日 | 2026-08-26 |
| 元データ | `LOLI4_Datafeed_2026Q3`（社内SQL Server `192.168.1.153`） |
| 名簿 | 12件（SDS 第15項で在否を書く国） |
| LOLI から読んだ行 | 983,214行 |
| 取り込んだ行 | **950,863行**（1行から複数番号が取れるので増え、番号が取れない行は入らない） |

取り出しは `scripts/sql/loli-inventories.sql`、取り込みは `scripts/seed-inventories.ts`。

---

## 1. 規制区分としては持たない

**インベントリは `regulation_categories` に入れていない。**

判定は登録されている区分をすべて見に行くので、インベントリを区分として入れると
**どの製品もすべてのインベントリに「該当」する**。判定表が使い物にならなくなる。

インベントリは「載っているか」と「その名簿での番号」を持つだけのもので、
含有率と閾値で当たりを決める規制とは性質が違う。
`inventories` と `inventory_rows` という別の表に持つ。

## 2. 加工してから入れる

行が持つのは**仕上がった値**——番号（`(5)-3714`）か、番号を持たない名簿の「該当」。
取り出しは取り込みのときに1回で済み、画面は出すだけになる。

取り出しかたは `scripts/seed-inventories.ts` の表に持つ。
当てるのは `@chem/shared` の `applyExtract`（取得条件の正規表現＋表示の書式）で、
**資料ごとに読み方を書かずに済む**。LOLI 以外の資料でも同じ仕組みで扱える。

**1つの物質に複数の番号が付く名簿では、番号の数だけ行を作る。**

## 4. 番号の扱いで気をつけたこと

### 1つのCASに複数の番号が付く

EINECS と KECI で起きる。同じ物質が別名で2回登録されている。

```
EINECS  100-78-7  "215-637-1" As 1,2,3-Propanetriol, acetate [1335-58-6];
                  "247-704-6" As Glyceryl monoacetate [26446-35-5]
KECI    100-78-7  "Present [KE-29298]" As ...;  "Present [KE-29309]" As ...
```

**正規表現を全件一致で当てて、取れた数だけ出す。**どちらか一方は選べない。

（`XML` カラムには `<row>` ごとに `<inv_num>` が入っており、そちらでも分けられる。
ただし LOLI 側で目にするのは `Data` の文字列なので、そちらに当てている。
`Data` に当てる形なら、LOLI 以外の資料——XML を持たないもの——でも同じ仕組みで扱える）

### TSCA は「該当」と出してはいけない

`value` はすべて `Present` だが、状態が別に入っている。

```
ACTIVE     78,043件
INACTIVE   39,507件
```

**INACTIVE は「名簿には載っているが、いま米国で商業流通していない」**という意味。
一律「該当」と出すと、そのまま輸出できるように読まれる。
`ACTIVE` / `INACTIVE` をそのまま出している。

### NZIoC も「該当」と出してはいけない

6割が「個別の承認は無い」と書かれている。

```
個別の承認は無いが、グループ基準の下で使用可能   39,686件
個別の承認は無いが、〜の成分としてなら使用可能   22,840件
承認あり（条件付き）                              866件
非有害                                            223件
```

**承認番号（`HSR…`）を持つ行だけを出す。**実データでは 4% しか一致しない
（60,136行のうち 2,689行）。残りは「載っているが個別承認は無い」ので、
番号としては出さないのが正しい。**一致率が低いこと自体は異常ではない。**

### 番号を持たない行がある

ENCS で 3,703行、ISHL で 5,481行が番号を持たない（`-` と理由だけ）。
「既存化学物質等として扱う」「日本薬局方に収載」などが書かれている。
正規表現に一致しないので取り込まない（一致率は ENCS 96%・ISHL 95%）。

## 5. 次に取り込むときに見ること

- **一致率**。取り込みが名簿ごとに出す。上の表と見比べる。
  0% になっていれば LOLI 側の書き方が変わった合図
- TSCA の `INACTIVE` の割合。増えていれば、輸出先での扱いに影響する
- 1つのCASに複数番号が付く行の数。増えていれば名寄せの見直しが要る
- **`scripts/seed-substances-from-links.ts` は流さないこと。**
  インベントリは物質マスタとは別の表に持っており、CASを物質マスタへ足す対象ではない

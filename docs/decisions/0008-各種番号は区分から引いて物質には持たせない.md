# 0008. 各種番号は区分から引いて、物質には持たせない

日付: 2026-08-24 / 状態: 採用

## 背景

物質の画面で、官報公示整理番号・EC番号・安衛法番号といった各種番号を見たいという要件がある。
当初は物質マスタに `substance_gazette_numbers`（物質ごとの官報公示整理番号）を置き、手入力していた。

しかしこれらの番号は**物質そのものの属性ではなく、あるインベントリが振っている番号**である。
官報公示整理番号は化審法の既存化学物質名簿が、EC番号は EINECS が振っている。
物質側に書き写すと、外部データベースとの**二重管理**になり、食い違いが起きる。

LOLI も同じ捉え方をしており、インベントリを普通のリストとして持っている
（ENCS 97,958件、安衛法 108,318件、EINECS 128,851件）。我々の規制区分と1対1で対応する。

## 決定

### 1. 番号体系ごとに規制区分を1つ立てる

番号は法文物質名の `officialNumber` に入れる。**列を増やさない。**

```
化審法
  ├ 第一種特定化学物質    … 政令番号
  ├ 優先評価化学物質      … 通し番号
  └ 既存化学物質名簿      … 官報公示整理番号   ← 番号のリストとしての区分
EU
  ├ EINECS              … EC番号
  └ REACH 附属書XVII     … エントリー番号
```

同じ物質名が複数の区分に出るが、これは安衛法の表示対象／通知対象と同じ形で既に扱えている。

### 2. 区分に「番号としての呼び名」を1列足す

空なら番号のリストではない。値が入っていれば、その名前で物質画面に出す。
**印と呼び名を1列で兼ねる。**

| 区分 | 番号としての呼び名 |
| --- | --- |
| 既存化学物質名簿（化審法） | 官報公示整理番号 |
| 安衛法インベントリ | 安衛法番号 |
| EINECS | EC番号 |
| 第一種特定化学物質 | （空） |

★**設定は区分そのものに持たせる**（別の対応表を作らない）。
別に持つと、区分を消したときに設定だけが取り残され、誰も気づかない。

### 3. 物質画面には「各種番号」の節を1つ置く

固定の欄ではなく**リスト**。呼び名の入っている区分の数だけ行が増える。

```
各種番号
  官報公示整理番号   (3)-2850      化審法 既存化学物質名簿
  EC番号            215-648-1     EINECS
```

- 引く道は `物質 → CAS番号 → CASリンク（現在版）→ 法文物質名 → officialNumber`
- 版は**現在版**に従う。新しい設定は要らない
- 並びは**法令の並び順 → 区分の並び順**
- 引けなかった番号は**行ごと出さない**（空行を出すと、登録漏れか対象外かが区別できない）

### 4. `substance_gazette_numbers` は役目を終える

物質ごとの手入力欄（「＋ 番号を追加」）は無くなる。読むだけになる。

## 結果

- 二重管理が無くなる。番号の出どころが1本になり、版と情報源で追える
- 新しいインベントリは、区分を登録して呼び名を書くだけで物質画面に並ぶ。画面のコードは触らない
- CASの無い物質は番号を引けない。仮のCAS番号を入れ、自社データでリンクを作れば引ける
  （CAS番号の欄は形式を強制せず、一般的な形に合わないときは警告を出すだけで保存は通る）

## 保留

引き当てられない番号を手で入れたい場面が出てきたら、別途相談する（2026-08-24 時点では作らない）。

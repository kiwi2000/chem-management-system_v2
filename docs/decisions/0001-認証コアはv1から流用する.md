# 0001. 認証コアは v1 から流用する

日付: 2026-08-13 / 状態: 採用

## 背景

v2 は「細かい動作を確認しながら作り直す」方針だが、認証まわりは画面の細部を詰めたい対象ではない。
一方で暗号処理の再実装はバグ混入のリスクが高く、混入しても目視では気づけない。

## 決定

以下は v1 からそのまま持ち込み、レビューのみ行う。作り直さない。

- `apps/web/lib/auth.ts`（Argon2id・セッション発行・ロックアウト）
- `apps/web/lib/totp.ts`（TOTP検証）
- `apps/web/lib/authz.ts`（requireUser / requireEditor / requireAdmin）
- `apps/web/lib/audit.ts`（監査ログ書き込み）
- `packages/shared/src/auth.ts`（入力スキーマ・ポリシー値）

変えるのはポリシー値（回数・時間）と画面だけ。

## 結果

- ログイン失敗の文言統一・ダミー検証による列挙対策・セッションのハッシュ保存といった、
  v1 で作り込んだ安全側の挙動をそのまま引き継げた
- v1 のコメントにあった `CLAUDE.md §1.1` 等の節番号参照は v2 の構成に合わせて直した

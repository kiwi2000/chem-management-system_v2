# 0014. 不純物は物質の「不純物パターン」で表し、CAS × パターンで合算する

日付: 2026-09-18 / 状態: 採用（仕様は `docs/steps/S21_不純物パターン.md`）

> この文書の「不純物パターン」「パターン」は、2026-09-19 に画面上の呼び名を**「不純物種別」**へ改めたもの。指すものは同じ。

## 背景

不純物・副生成物として含まれる物質は、規制によっては裾切値以上でも非該当になる（化審法の届出、
K-REACH の登録など）。一方で安衛法・化管法・RoHS は不純物でも対象にする。
判定は含有率と CAS だけを見ていたので、この違いを表せず、判定修正で 1 行ずつ直すしかなかった。

候補は 3 つあった。

1. 組成の行（製品 × 物質）に「判定対象外」と理由を付ける
2. 組成の行に「由来」（主成分・添加剤・不純物…）を付け、規制区分に「不純物を除外する」を持つ
3. **物質の属性として「不純物パターン」を持ち、パターンごとに除外する規制区分・法文物質名を設定する**

## 決定

3 を採る（利用者の提案・決定）。

- 「同じ該非判定になる不純物どうしを同じパターンにする」ので、設定はパターンの数だけで済み、物質の数に比例しない
- 物質の属性なので、組成の行を変えずに済み、原材料をたどってもそのまま伝わる。
  仕入先ごとに同じ CAS を分けて登録する、いまの運用の延長で扱える
- **CAS 合算は CAS × パターンで行い、パターンをまたいで足さない。**
  「不純物と決めた物質は、その規制に対しては必ず非該当」という運用の前提に立つ。
  パターン 0 と 1 を足すと閾値を超える、という場合は起きないものとして扱う（利用者の判断）
- 代表物質も CAS × パターンごとに 1 つ。合算の行に出す名称がその組で決まるため
- 除外の設定は規制区分単位を基本に、法文物質名単位で両方向に上書きできる。
  区分単位で決まる規制（化審法の届出）と、法文物質名単位で決まる規制（副生 PFOA、POPs の UTC、REACH 附属書 XVII のエントリ）の両方があるため
- 除外は無条件。濃度の条件が付く除外は、パターンの割り当てで利用者が吸収する

## 見送ったもの

- 1 は個別事情（硬化して残らない、工程で揮発する）の受け皿としては有用だが、規制の決まりを表すものではない。
  要望が続けば、別の仕組みとして足す
- 2 は組成の行に属性を増やす。同じ物質が主成分にも不純物にもなり得る点は 3 と同じだが、
  原材料側で付けた由来を親製品でどう扱うかが決まらず、3 のほうが素直だった

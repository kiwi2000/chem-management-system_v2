# 0012. 判定の単位はまとめる単位と同じ（区分でまとめる区分は区分、それ以外は法文物質名）

日付: 2026-09-15 / 状態: 採用

## 背景

判定結果（`product_judgements`）は「製品 × 規制区分 × 法規制バージョン」で1行だった（決定 0010）。
区分の行に該当／非該当と「判定修正」が付き、当たった法文物質名はその下に根拠として並ぶだけだった。

利用者から「優先評価化学物質・表示対象物質・通知対象物質のように、法文物質名ごとに該非が決まる区分で、
区分に該当／非該当が出ているのはおかしい」と指摘があった。安衛法の表示対象物質のように裾切値が
法文物質名ごとに違う区分では、該非は法文物質名ごとにしか決まらない。区分の該当は
「その区分のどれかの法文物質名に当たった」という積み上げでしかなく、
「この法文物質名は非該当」と人が判断したいときの置き場所も無かった。

利用者の整理: **まとめる単位が該非判定の単位。**区分でまとめる（区分全体で含有率を合算する）区分だけが
区分で判定し、それ以外は法文物質名で判定する。法文物質名でまとめない（CAS ごとに閾値と比べる）ときも、
どれかの CAS が超えればその法文物質名が該当なので、単位は法文物質名。
区分の閾値は「区分内の法文物質名の閾値の既定値」であって、判定の単位を決めるものではない。

## 決定

### 1. 判定の行は「製品 × 判定の単位 × 法規制バージョン」で1行

- 判定の単位: 区分の `aggregation` が NONE 以外（区分でまとめる）なら区分そのもの、それ以外は法文物質名
- `product_judgements.statutory_substance_id` を足し、区分そのものが単位のときは空文字
  （null にすると一意キーに使えない）。外部キーは張らない（根拠の行 `product_judgement_hits` と同じ）
- 法文物質名が単位の区分では、**製品にその CAS が入っている法文物質名だけ**を行にする。
  閾値に届かなかったものも「非該当」として残し、根拠に入っている CAS と含有率を持つ
  （組成の表の「含有率不足による非該当」と同じもの。「該当のみ表示」を外すと見える）。
  入っていない法文物質名は行にしない（表示対象物質は 2,339 件ある）
- 要確認の理由は単位ごとに付ける。区分全体にかかる理由（中身の分からない原材料、深すぎて展開しきれない、
  均質材料あたり）は、その区分の全部の行に付ける。換算係数が無い理由は、その法文物質名にだけ付く
- `judge()`（`lib/judge-calc.ts`）は `{ unit: "category" | "substance", units: JudgeUnit[] }` を返す

### 2. 人の判断は「製品 × 判定の単位」

- `product_decisions` に `statutory_substance_id` を足し、一意キーを (製品, 区分, 法文物質名) にする
- 前提（`premise`）は「その単位で見た CAS の組」（`premiseOf(unit)`）。引き継ぎの決まりは 0010 のまま
- 確認・修正の API は判定の行を相手にする（`PUT /api/products/[id]/judgements/[judgementId]`）
- **以前の区分ごとの判断は捨てる**（移行で削除し、判定し直したあと要確認から見直す。利用者決定）

### 3. 画面

- 製品の判定表: 法文物質名が単位の区分では、区分の行は国・法律と同じ「n 件中 m 件に該当・要確認 k 件」の
  見出しだけ。該当／非該当のラベル・警告・「判定修正」は法文物質名の行に付く。
  区分そのものが単位の区分（と、根拠を伏せた相手）は区分の行にラベルと判定修正が付く
- 「該当のみ表示」（既定オン）は判定の単位の行を絞る。外すと含有率不足の非該当も並ぶ。
  ボタンの位置と文言は変えない
- 見出しの件数（n 件中 m 件に該当・要確認）は判定の単位の数
- 製品一覧の「法規制」列は**当たった区分の数のまま**（同じ区分に法文物質名が何件当たっても 1）。
  帳票の「該当した規制区分の数」も区分の数のまま。帳票の判定の表は判定の単位ごとに 1 行
- 区分の画面の「該当製品」は 1 行＝製品 × 判定の単位。該非と要確認も行ごと
- 根拠を伏せる相手（組成を見られない人）には、法文物質名の名前も根拠なので、
  区分ごと（逆引きでは製品ごと）に 1 行にまとめて該非と確認の要否だけを出す

### 4. 「要再計算」

移行で判定を捨てるので、`rejudgeNeeded()` の「判定が無い製品」は
「組成（展開結果）があるのに現在の版の判定が無い製品」で数える。移行のあとは管理者が
「全製品を判定し直す」を押す（更新のご案内に書く）。

### 5. 決めていないこと

- 法文物質名の閾値を「空＝区分の既定値に従う」にする作り（いまは登録時に区分の値を写している）。
  次に閾値の扱いを直すときに一緒に行う

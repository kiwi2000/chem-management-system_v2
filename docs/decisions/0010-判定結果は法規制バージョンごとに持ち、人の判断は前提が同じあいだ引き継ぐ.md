# 0010. 判定結果は法規制バージョンごとに持ち、人の判断は前提が同じあいだ引き継ぐ

日付: 2026-09-12 / 状態: 採用

## 背景

判定結果（`product_judgements`）は「製品 × 規制区分」で1行だけ持ち、判定し直すたびに
行ごと作り直していた。どの法規制バージョンで出したかは控えとして書いてあるだけで、
**現在のバージョンを切り替えても判定は計算し直されない**。

本番で次の取り違えが起きた。2026Q3 に USER の非該当リンクを登録して製品を判定し（非該当）、
現在のバージョンを 2026Q2 に切り替えたところ、製品の画面には 2026Q3 で出した「非該当」が
残ったまま見えた。利用者は「2026Q2 でも非該当になった」と読んだ。見出しの小さな
バージョン表示と赤い注意だけでは、前の版の結果であることが伝わらなかった。

もう1つ、人の確認・上書き（誰が・いつ・何を根拠に）は判定の行に書いていたので、
判定し直すと消える。版が変わるたびに全製品の判断を入れ直すことになり、入れ忘れた版で
客先に「該当」と答える事故につながる。

## 決定

### 1. 判定の行は「製品 × 規制区分 × 法規制バージョン」で1行

- `version_id` を必須にし、一意キーに加える。版を消せばその版の判定も消える（cascade）
- 判定し直すとき消して作り直すのは**現在の版の行だけ**。別の版の行は残す
- 画面・一覧・法律の側からの逆引き・書類・「該当法規制」の選択肢は、**現在の版の行だけ**を見る。
  版で絞る場所は `lib/current-version.ts` の `getCurrentVersion()` を通す
- 現在のバージョンを切り替えても何もしない。その版の判定が無い製品には、判定表に
  「法規制バージョン ○○ の判定はまだありません」と出し、左メニューの「要再計算」を出す
  （`rejudgeNeeded()` に「別の版では判定してあるのに現在の版の判定が無い製品があるか」を足した）

自動で計算し直さないのは、全製品の判定が数十分かかるため。また前の版の結果を残せば、
規制改正のときに版を切り替えて見比べられる。

### 2. 人の判断は `product_decisions`（製品 × 規制区分）に持つ

- 「確認する」（判定はそのまま、見た印）と「判定を変える」（該当／非該当を人の値に）の両方
- 判断したときの**システムの結果**（`system_verdict` と `premise`）を一緒に控える。
  `premise` は「どの法文物質名に、どのCASで当たったか」を並べ替えてつないだ文字列
  （`lib/judge-decision.ts` の `premiseOf`。移行 SQL も同じ作りかたで既存の行を埋めている）。
  含有率は入れない。同じ物質に同じ法文物質名で当たっているなら、量が少し動いても
  「この物質は法文物質名の形ではない」という判断は変わらないため
- 判定し直したとき（`judgeProduct`）に `applyDecision` で当てはめる。
  前提が同じなら判断をそのまま当てはめて要確認は付けない。違えばシステムの結果を出し、
  **要確認にして理由 `decisionDropped` を足す**（黙って結果が変わると判断した人が気づけない）。
  画面には以前の判断（該当／非該当／確認のみ・誰が・いつ・根拠）を添える
- 人が判定表で判断し直すと、新しい前提で上書きされる
- 判定の行の `decided_*` は当てはめた結果の写し（画面に出すため）

「別の版では人が判断するまで必ず要確認にする」案は採らなかった。法律に動きの無い物質まで
版のたびに全製品を見直すことになり、印が無視されるようになるため。

### 3. 「特定の製品用のUSERデータ」は作らない

USER データ（法文物質名 × CAS × 版）は全製品に効く。製品ごとに結果を分けたい場面は
製品側の判断（2.）で受ける。規制そのものが変わったときは規制区分を新しく作る決まり
（`chem-regulation-change-by-category`）なので、区分が変われば判断は自然に効かなくなる。

「50-00-0A のような疑似CASで別物質にする」運用も検討したが、LOLI/CHRIP のリンクが全部外れ、
金属換算も効かず、書類に実在しない番号が出るので採らなかった。

## 影響

- 移行 `20260912120000_judgement_per_version`。版が空の古い行は現在の版のものとみなし、
  現在の版が無ければ消す。既に確認・上書きしていた行は `product_decisions` へ前提ごと移す
- `scripts/copy-to-prod.ts` は判定の版を本番の版に読み替え、本番に無い版の判定は持って行かない
- 判定表の警告に「以前の人の判断を当てはめなかった」が増えた。マニュアル「法規制判定」に
  「法規制バージョンと判定」の節と、「判定を直す」の引き継ぎ規則を書いた

# 0009. Excel・Word のファイルを様式として預かる

日付: 2026-08-30 / 状態: 採用

## 背景

様式は画面でブロックを積んで作っていた。ブロックは見出し・文章・項目の並び・表・組織など、
こちらが用意したものに限られる。**罫線の引き方・セルの結合・ヘッダー／フッター・ページ番号・
ロゴ・縦書きは出せない。**

利用者から「Word や Excel だともっと柔軟なテンプレートが作れるのでは」と問われた。実務では、
**取引先から Excel の調査票が送られてくる。**その形をブロックで真似ることはできないので、
いまのままでは、画面で作った回答書を別途こちらの様式で返すか、手で写すしかない。

## 決定

**様式に「作りかた」を持たせ、Excel・Word のファイルそのものを預かれるようにする。**
画面で組む方式は残す（簡単な帳票はそのほうが速い）。

### 1. 差込札の文法は1つだけ

```
{product.code}              1つの値。画面の様式で使っている差込名と同じ
{composition.casNumber}     表の列。その札を置いた行が、明細の数だけ増える
```

**繰り返しの開始・終了の印は作らない。**Excel・Word でよくある `{#loop}…{/loop}` を採らなかったのは、
**相手の様式にこちらの都合の行を足させたくない**ため。調査票のセルは相手が決めている。

知らない札は空にする。「？」や札のままを残すと、書いた文字と見分けが付かないまま相手へ出る。

### 2. 値集めは変えない

`lib/doc-data.ts` の `collectFor()` をそのまま使う。
**非公開組成の伏せかたが、画面の様式とファイルの様式で分かれない。**
組成を見られない人が作れば、明細は0件になり、その行ごと消える。

### 3. Excel は exceljs、Word は自前で XML を触る

| | 使うもの | 理由 |
| --- | --- | --- |
| Excel | exceljs（MIT） | 行の複製・書式・結合を持っているものを自分で書くのは割に合わない |
| Word | JSZip ＋ 自前 | `<w:tr>` を深さで数えて複製するだけ。**ファイルを作り直さないので、図形も何も落ちない** |

**exceljs は読んで書き直すので、図形・グラフ・ピボットは落ちることがある。**
これはマニュアルに書き、預けたら一度作って確かめてもらう。
Word 側を自前にしたのは、この作り直しを避けられるため。

### 4. 出すのは .xlsx / .docx のまま。PDF にはしない

サーバーで PDF にするには LibreOffice が要り、入れ物が数百MB太る。
印刷は Word・Excel から行ってもらう。

### 5. 作った記録は今までどおり「記録だけ」

`GeneratedDocument` にファイルは残さない。残せば、あとで権限が変わった人が古いものを取れてしまう。
ファイルの様式では紙面も残せないので、何を出したかだけを控える。

### 6. 受け取る前に断る

- マクロ付き（`vbaProject.bin`）は受け取らない
- 5MB、展開後40MB、項目2000までで打ち切る（zip 爆弾よけ）
- 種類の違うファイル（Excel と言って Word）は断る

## 影響

- `document_templates` に `kind` と `file_data` / `file_name` / `file_updated_at` が増える。
  既にあるものは `BLOCK` のままで、何も変わらない
- **まとめて作れるのは画面で組んだ様式だけ。**ファイルの様式は1枚ずつ別のファイルになるので、
  続けて刷るという形にできない
- 画面の中でプレビューできない。落として開いてもらう

# 1. 共通事項

## 1.1 画面構成（認証後の全画面共通）
```
┌───────────────────────────────────────────────────────────────┐
│ ヘッダー（固定）                                               │
├───────────────────────────────────────────────────────────────┤
│                                                               │
│   コンテンツ領域（中央寄せ・最大幅 max-w-4xl〜6xl）           │
│                                                               │
└───────────────────────────────────────────────────────────────┘
```

## 1.2 ヘッダー
```
┌───────────────────────────────────────────────────────────────┐
│ 化学物質管理システム  物質 製品 法規制 リンク 金属換算 取込/出力 [管理] │
│                         山田(user@..) 《特権ユーザー》《参照のみ》 ▼日本語 [ログアウト] │
└───────────────────────────────────────────────────────────────┘
```
| 要素 | 内容・表示条件 |
|---|---|
| ロゴ「化学物質管理システム」 | クリックでホーム（/）へ |
| ナビ | 物質/製品/法規制/リンク/金属換算/取込・出力。「管理」は**システム管理者のみ**表示 |
| ユーザー名 | `displayName`（メール）。未設定は「(名前未設定)」 |
| ロールバッジ | システム管理者／特権ユーザー／非特権ユーザー |
| 「参照のみ」バッジ | **編集権限なし**のとき表示 |
| 言語切替▼ | **有効ロケールが2件以上**のとき表示。選択→即保存し再読込 |
| [ログアウト] | サインアウト→/login |
| （未ログイン時） | ヘッダー非表示 |

## 1.3 共通コンポーネントの挙動
- **一覧＋検索**: 検索欄＋[検索]（Enterでも実行）。部分一致・大小文字無視。ページング50件/頁、下部「全 N 件」「X / Y」[前へ][次へ]（端で無効化）。
- **削除**: 確認ダイアログ→OKで削除。参照ありは1回目が警告文（件数入り）→再確認ダイアログでOKすると強制削除。
- **保存ボタン**: 処理中は「保存中...」等に変化し無効化。
- **メッセージ表示**: フォーム下に色付き帯。赤=エラー、無地=情報/警告（警告は先頭に「⚠️」）。

## 1.4 権限による表示制御（全画面共通ルール）
| 対象ユーザー | 挙動 |
|---|---|
| 編集権限なし | 一覧の[＋新規登録][削除][複製]等を**非表示**。[編集]→「表示」表記。フォームは入力欄を**無効化(グレー)**、[保存]非表示、上部に注記「参照のみ: 編集権限がないため、登録・変更・削除はできません（判定実行とダウンロードは可能です）」 |
| 非特権ユーザー | 製品の非公開/組成公開チェックボックスを**非表示**。非公開製品は一覧・詳細に出ない。組成非開示製品では組成エディタの代わりに注記 |
| システム管理者以外 | ヘッダー「管理」非表示、/admin・/admin/locales はデータ取得時に「この画面はシステム管理者のみ利用できます」 |

### 組成エディタ（カード「原組成」）
```
┌ 原組成 ───────────────────────────────────────┐
│《表》種別《物質》│構成要素(コード｜名称)│含有率(wt%)[__]│balance☑│[削除]│
│ 入力済み合計（参考）: X%                       │
│┌ 構成要素を追加 （編集可のみ）───────────────┐│
││ ▼物質/原材料  [コード / 名称で検索__][検索]  ││
││ （候補リスト最大10件・クリックで追加）        ││
│└─────────────────────────────────────────────┘│
│ （エラー/警告/結果メッセージ）                  │
│ [組成を保存]                                    │
└───────────────────────────────────────────────┘
```
| 列 | コントロール | 入力チェック |
|---|---|---|
| 種別 | バッジ（物質/原材料） | |
| 構成要素 | 検索選択（追加時） | 物質 or 原材料利用可の製品。自己・重複・非公開(非特権)不可 |
| 含有率(wt%) | text | 0<x≤100・小数6桁。balance時は無効「自動補完」 |
| balance | checkbox | 1製品1件 |
- [組成を保存]: 成功「保存しました。既知成分合計 X%（・balance Y%）」。エラー（複数同時・保存されない）例:「循環参照が発生するため登録できません…」「同一の物質が複数行に指定されています」「「コード」は原材料利用可フラグがオフのため…」、合計系（設定モード依存）。
- 組成非開示×非特権のときは、エディタの代わりに注記「この製品の組成は非開示です（…特権ユーザーのみ閲覧・編集できます）」。

```
┌ 展開・統合組成（物質レベル）           [展開を実行] ┐
│《表》物質コード│CAS番号│名称│統合後含有率(wt%)      │

│ 使用リンクバージョン ▼[2026Q2（有効）]  [判定を実行]│
│ （緑帯）判定完了（バージョン X）。最終該当区分: …  │
│《表》法律│規制区分│該当《該当/非該当》│算定値│結果《最終該当/抑制》│
│    └ 根拠（寄与物質 N 件）▼ …                      │
```

- 結果表: 該当＝赤バッジ、最終該当/抑制バッジ。根拠を開くと寄与物質・情報源。非開示×非特権は明細マスク＋注記。

# 5. メッセージ一覧（画面横断）
| 種別 | 文言 | 契機 |
|---|---|---|
| 認証 | ログインが必要です | 未認証API(401) |

| 情報 | 保存しました。／取込完了: … | 保存・取込成功 |
| 警告 | ⚠️ 同一CAS番号（X）の物質が既に N 件… ／ 含有率合計が100%未満です… | 保存時警告 |

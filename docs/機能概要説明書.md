# ケミカルコンプライアンス支援システム　機能概要説明書

**製品の組成を登録すると、各国の化学物質規制への該非を自動で判定し、その根拠を残すシステムです。**

本書は、本システムでできることをまとめたものです。
画面の細かい操作は、システム内のユーザーマニュアルに用意しています。

---

## 1. 何をするシステムか

**製品の組成を登録すると、どの法規制のどの規制区分に該当するかを自動で判定します。**

各国の化学物質規制は、法律・規制区分ごとに対象物質と閾値（裾切値）が定められています。
自社製品の該非を人手で照合すると、製品数と規制区分数の掛け算になり、
規制が改正されるたびにやり直しになります。本システムは、その照合を肩代わりします。

判定するだけでなく、**判定の根拠がどこから来たのかを全部たどれる**ようにしてあります。
どの資料の、いつ時点の版で、どの CAS 番号が、どの法文物質名に結び付いた結果なのか。
お客様先や監査で「なぜこの結論なのか」を説明するための情報です。

### 3 つの特長

| | 特長 | 何がうれしいか |
| --- | --- | --- |
| ① | **根拠をたどれる判定** | 「該当」の一言ではなく、どの法律の・どの規制区分の・どの法文物質名に・どの CAS で該当したかまで残ります。人が修正した判定も、誰が・いつ・なぜ、と一緒に残ります |
| ② | **資料の版と優先順位を管理** | LOLI・CHRIP・公的機関・自社の資料を版ごとに持ち、食い違いは順位で決めます。版を上げたら前の版との差分が出るので、改正の影響がすぐ分かります |
| ③ | **自社様式のまま出せる** | 不使用証明書や含有調査回答書を、自社や取引先の様式（PDF・Excel・Word）で出せます。様式が増えてもシステムを直しません |

### こんな場面で効きます

| 場面 | 本システムでは |
| --- | --- |
| 取引先から含有調査（特定物質の含有有無・含有率の照会）が来た | CAS 番号や物質名で逆引きすると、どの製品に含まれ、どの法律のどの規制区分に該当するかが一覧で出ます。回答書は自社様式の帳票で出せます |
| 規制が改正され、対象物質が増えた | 新しい版を取り込み、前の版との**差分**を見て、影響のある製品を選んで判定し直します。全製品をやり直す必要はありません |
| 資料によって該非の記載が食い違う | データソースに優先順位を付け、どれを採るかを決めます。採られなかった資料の記載も消さずに残ります |
| 監査や顧客に「なぜこの結論か」を説明する | どの資料の、いつの版の、どの CAS が、どの法文物質名に当たったのか。判定の根拠を全部たどれます |
| 不純物として入っているだけで、その規制では対象外にしたい | 物質に不純物種別を付け、規制区分ごとに非該当と決められます。判定には「不純物のため非該当」と根拠が残ります |
| 閾値ぎりぎりの配合を検討している | 閾値未満で非該当になった物質も「含有率不足による非該当」として見えます。配合を変えた場合の該非を、その場で確かめられます |
| 担当者が替わった | 人が直した判定には、誰が・いつ・なぜが残ります。前提が変わらない限り、版を上げても引き継がれます |

| 項目 | 内容 |
| --- | --- |
| 対象業務 | 化学物質の法規制対応、含有調査への回答、SDS 作成の前段 |
| 主な利用者 | 品質保証・環境安全・製品開発の担当者 |
| 動作環境 | 社内サーバーまたは国内 VPS。標準は Ubuntu ＋ Docker。**外部サービスへの通信は行いません** |

## 2. 全体像

大きく 4 つの部分でできています。

```
  ①登録する
     物質 ／ 製品・組成 ／ 法規制
        │
        ▼
  ②判定する
     組成を展開 → CAS で突合 → 閾値と比較
        │
        ▼
  ③出す
     PDF 帳票 ／ Excel・Word ／ TSV 書き出し

  ④運用する（①〜③のすべてに掛かる）
     権限 ／ 承認 ／ 履歴 ／ 多言語
```

1. **登録する** … 物質・製品（組成）・法規制のデータを持ちます
2. **判定する** … 組成と法規制を突き合わせ、該当・非該当を出します
3. **出す** … 判定結果や製品情報を、自社の様式の帳票（PDF・Excel・Word）にします
4. **運用する** … 権限・承認・履歴・多言語など、複数人で長く使うための仕組みです

このうち②の判定と、その土台になる規制データの版・出典の管理（4 章）が、本システムの中核です。

## 3. 登録するもの

### 3-1. 物質

CAS 番号・名称（日本語／英語／別名）・不純物種別・備考などを登録します。

- **CAS 番号は必須ではありません。**ポリマー・UVCB・企業秘密の物質も登録できます
- **CAS 番号は打っているそばから形を確かめます。**桁の並びが CAS の形でなければ
  「CASの形式ではありません」、最後の 1 桁（チェックデジット）が前の数字と合わなければ
  「チェックデジットが合っていません」と欄の下に出ます。1 桁の打ち間違いは別の物質の番号に
  なってしまうので、この 2 つを分けて知らせます。システム設定で形を強制すれば、どちらも登録できません
- **同じ CAS 番号の物質を、仕入先ごとに分けて登録できます。**そのうち 1 件を「代表」に指定し、
  合算表などに出す名称を決めます。登録するとき、同じ CAS の物質が既に何件あるかを知らせます
- 化審法番号・EC 番号・TSCA 番号などの**各種番号は、手で入れません。**
  後述のインベントリ（各国の既存化学物質目録）から自動で引いて表示します
- **不純物種別**を持ちます。不純物として入る物質は種別を分けて登録し、
  規制ごとに非該当にできます（5-4）
- 自社固有の項目（管理区分・用途メモなど）を、**管理者が項目定義を足して増やせます**

### 3-2. 製品・原材料と組成

製品の組成（構成物質と含有率）を登録します。

```
  製品「塗料 A」
   ├─ 物質　トルエン　20%
   ├─ 原材料「硬化剤 B」　30%
   │    ├─ 物質　ビスフェノール A　50%　→ 製品では 15%
   │    └─ 物質　添加剤 C　50%　→ 製品では 15%
   └─ 物質　酸化チタン　50%
```

- 組成の行には、**物質だけでなく他の製品（原材料）も入れられます。**
  購入した調合品をそのまま 1 行にし、その中身は原材料側で持つ、という持ち方ができます
- 原材料の階層は**何段でも**構いません。判定のときは末端の物質まで自動で展開します
- 合計が 100% になる「残り」を一度の操作で入れられるなど、日々の入力の手間を省く工夫を入れています
- 組成を保存すると、その製品とそれを原材料に使う製品の**判定がその場で計算し直され、同じ画面の判定の表も
  すぐ新しくなります**
- 末端の物質まで下ろして同じ CAS 番号をまとめた**「原材料展開・CAS 合算」の表**が、組成の下に出ます。
  右側には該当法規制の列とインベントリの列が並び、どちらも最初は畳んで件数だけを出し、
  見出しの「>」で地域・国・法律・規制区分、あるいはインベントリごとの列に分かれます（5-1）

### 3-3. 法規制

**地域 → 国 → 法律 → 規制区分 →（分類）→ 法文物質名**の階層で持ちます。

```
  地域　　　　　アジア
   └ 国　　　　日本
      └ 法律　　　　　　化審法
         └ 規制区分　　第1種特定化学物質　← 閾値をここで決める
            └［分類］　（任意の中分け）
               └ 法文物質名　　ポリ塩化ビフェニル
                  └ 規制対象 CAS　1336-36-3 ほか
```

「法文物質名」は、法律が条文で名指ししている物質名です（例：「ポリ塩化ビフェニル」）。
物質マスタとは別物で、**法律の言葉をそのまま持つ**ための層です。

- 区分ごとに**閾値（下限・上限、以上／超過の別）**を持ちます
- 法文物質名の側で閾値を上書きできます。空欄なら区分の値を継ぎます
- **判定に使わない区分**（参考として持つだけ）を指定できます
- **適用開始日・適用終了日**を持てます。施行前の区分で当たった場合は、判定にその旨が出ます
- 同じ物質でも区分によって閾値が違う場合（安衛法の表示対象と通知対象など）は、
  それぞれの区分に別々に登録します
- 法律の一覧は**法律 → 規制区分 → 分類**の順に開けます。分類のある区分にだけ「>」が付き、
  分類のコードを押すと、その分類を選んだ状態で法文物質名の一覧が開きます

![法律の一覧。法律を開くと規制区分が並び、分類のある区分はさらに分類まで開けます。規制区分の既定の閾値・スコア・法文物質名の数が見えます](images/overview/laws.png)

### 3-4. 規制対象 CAS（法文物質名と CAS 番号の結び付き）

法文物質名は法律の言葉なので、そのままでは組成と突き合わせられません。
**「この法文物質名は、この CAS 番号を指す」**という結び付きを持って、初めて判定できます。

この結び付きは外部のデータから作ります。その扱いは次章で詳しく説明します。

各国が持つ既存化学物質の目録を取り込んであります。
判定には使わず、**物質の詳細に「各種番号」として出す**ための出典です。

## 4. 規制データの版と出典の管理

**ここが本システムの中核です。**規制情報は「いつ時点の、どの資料か」で中身が変わります。
同じ CAS 番号でも、資料が違えば該当・非該当が違うことがあり、版が違えば載っている物質が違います。
その違いを消さずに持ち、**どれを信じてどう判定したかを、あとから説明できる形**にしてあります。

### 4-1. データソースとバージョン

| 用語 | 意味 |
| --- | --- |
| データソース種別 | どこから来たデータか（LOLI、CHRIP、公的機関、自社で作ったものなど） |
| バージョン | いつ時点のものか。コード（2026Q3 など）と**基準日**を持ちます |
| 現在のバージョン | 判定に使う版。✅ が付きます |

```
  バージョン（基準日の新しい順）

   2026Q3　基準日 2026-07-01　✅ 判定に使う版
      ▲
      │ ここを比べると、追加・削除・変更が一覧で出る
      ▼
   2026Q2　基準日 2026-04-01
   2026Q1　基準日 2026-01-01
```

**どちらが新しいかは、コードの文字ではなく基準日で決めます。**「2026春」でも「v3」でも
好きな名前を付けられるのは、そのためです。

*外部データベースの画面。データソース種別、バージョン、バージョンごとのデータソース（優先順位・色・印・有効・リンク数）、その下に規制対象 CAS の表*

### 4-2. 複数のデータソースに優先順位を付けられます

資料によって書いてあることが違うことがあります。**そのときどれを信じるかを、順位で決めます。**

```
  CAS 1336-36-3 について、資料の言い分が食い違う場合

   順位1　CHRIP　「非該当」　← ●使用（この行が採られる）
   順位2　LOLI 　「該当」　　　 使われない
   順位3　自社 　（記載なし）

   判定 … 非該当（上位の資料が、下位の資料の内容を打ち消す）
```

| CAS 番号 | 該非 | データソース | 使用 |
| --- | --- | --- | --- |
| 1336-36-3 | 非該当 | CHRIP（順位 1） | ● |
| 1336-36-3 | 該当 | LOLI（順位 2） | |

この例では、順位の高い CHRIP が「非該当」と言っているので、LOLI に「該当」と書いてあっても
当たりません。**順位の高い資料で、下位の資料の誤りを打ち消せます。**

- 1 つの CAS 番号につき、いちばん順位の高い資料の 1 行にだけ「使用」の印が付きます
- 印の付いていない行も**消さずに残します**。「別の資料はこう書いている」が見えるためです
- 順位は画面上で行をつかんで入れ替えられます
- データソースごとに**色と印（記号）**を決められ、判定結果の表に出ます。
  どの資料から来た判定なのかが、表を見ただけで分かります

### 4-3. データソースを一時的に外せます（有効／無効）

「この資料を使わなかったらどうなるか」を、データを消さずに確かめられます。

```
  バージョン 2026Q3 のデータソース

   順位1　USER 　有効 ☑
   順位2　LOLI 　有効 ☐　← 外すと、この版ではこの資料は無いものとして扱う
   順位3　CHRIP　有効 ☑

   LOLI の規制対象 CAS は消えない。チェックを付け直せば、そのまま戻る
```

- 外した資料の規制対象 CAS は、判定・「使用」の印・製品の合算表・帳票・物質のスコアの
  どれにも出なくなります
- **行は消えません。**契約が切れた資料を残したまま外す、1 つの資料だけで判定した結果を見比べる、
  といった使いかたができます
- 外したり付けたりすると「要再計算」の印が出ます。影響のある製品を選んで「再計算」できます（5-10）

### 4-4. 規制対象 CAS はその場で直せます

取り込んだ資料の結び付きに誤りを見つけたときは、規制対象 CAS の表で**該非・備考・CAS 番号**を
その場で直せます。上位の資料（自社の USER）に正しい行を足して打ち消す方法と、
誤った行そのものを直す方法の、どちらも取れます。

### 4-5. 前のバージョンとの比較

規制データを新しい版に更新したとき、**何が変わったのかを一覧で確かめられます。**

- 規制対象 CAS の画面で比較する版を選ぶと、**追加・削除・変更**の印が付いた差分だけが出ます
- 件数の要約（＋追加 −削除 ±変更）も出ます
- 製品の判定結果の側でも「差分あり」を押すと、**前の版には無かった結び付き**に印が付きます。
  版を上げて新しく当たるようになったものが、製品ごとに分かります
- 判定結果は**バージョンごとに保存**されるので、前の版の判定も残ります。
  「去年の申告は、当時のこの版で判定した」が後から言えます

![LOLI の 2026Q3 を 2026Q2 と比較したところ。追加・削除・変更の印が付いた差分だけが出ます（＋45,369 −5,407 ±5,357）](images/overview/external-db-diff.png)

### 4-6. 取り込み

規制リスト・製品と組成・物質を、ファイルでまとめて取り込めます。

- **いきなり本体を書き換えません。**いったん一時領域に取り込み、中身を確かめてから「反映」します
- 一時領域の表では、どの行が新規で、どの行が変更かが分かります
- 当方が用意するデータセットのほか、**自社で作った規制リスト**も取り込めます

## 5. 判定

### 5-1. 何を突き合わせているか

製品の組成を末端の構成物質まで展開し、CAS 番号で規制対象 CAS を引き、閾値と比べます。

- **原材料の展開** … 原材料の階層をたどり、末端の構成物質と製品全体での含有率を計算します。
  原材料の組成が変わっても、その原材料を使う製品は自動で判定し直されます
- **CAS 合算** … 同一 CAS が複数の原材料経路から入る場合、合算してから閾値と比べます
- **金属換算係数** … 「鉛及びその化合物」のように元素換算で規制される場合、
  化合物の含有率を元素の量に換算してから判定します。係数は画面で管理できます

```
  製品の組成
     │  ①原材料の階層をたどり、末端の物質まで展開する
     ▼
  物質と含有率
     │  ②同じ CAS を合算する（必要なら金属換算係数で元素量に換算）
     ▼
  CAS 番号ごとの含有率
     │  ③規制対象 CAS から法文物質名を引く（資料の優先順位を適用）
     ▼
  当たった法文物質名
     │  ④閾値と比べる
     ▼
  結果 … 該当 ／ 含有率不足による非該当 ／ 非該当
         ＋ 適用条件などがあるものには「要確認」が付く
```

### 5-2. 判定の単位

規制区分の設定によって変わります。

| 区分の設定 | 判定の単位 |
| --- | --- |
| ほとんどの区分 | **法文物質名ごと**。製品にその CAS が入っている法文物質名だけが行になります |
| 区分全体で合算する区分 | **規制区分そのもの**。区分の中の該当物質を合計して判定します |

**「どの号に当たったのか」まで出ます。**単に「この法律に当たる」ではなく、
「この法律の、この区分の、この法文物質名に当たった」という粒度で結果が残ります。

### 5-3. 閾値未満の物質（含有率不足による非該当）も確認できます

**非該当を、非該当と確かめられることが重要です。**

- CAS 番号は規制に載っているが、いまの配合では閾値に届かない、という物質を
  **「含有率不足による非該当」**として別に出せます（オレンジの三角の印）
- 「本当に当たらないのか」「配合を少し変えたら当たるのか」を確かめるときに使います
- ボタンの右に件数が出るので、押す前に何件あるかが分かります
- 出るのは**含有率が閾値に届かなかったものだけ**です。不純物種別で非該当にしたものや、
  判定に使わない区分（IARC の分類など）は、含有率に関係なく非該当なので混ぜません
- 含有率を変えた場合にどうなるかは、判定対象日や再計算で確かめられます

### 5-4. 不純物として含む物質は、規制ごとに非該当にできます

不純物・副生成物として含まれる物質は、**規制によっては裾切値以上でも非該当**になります
（化審法の届出、K-REACH の登録、TSCA の新規化学物質届出など）。一方で、安衛法の表示・通知、
化管法、RoHS のように**不純物でも対象になる規制**もあります。この違いを設定で表せます。

**「不純物種別」**を物質に付け、種別ごとに「どの規制区分で非該当にするか」を決めます。

```
  物質                        不純物種別

   トルエン（主成分用）        0 不純物ではない
   トルエン（不純物）          1 不純物
                                 │
                                 ▼
  「1 不純物」の設定           化審法 優先評価化学物質　☑ 非該当にする
                              安衛法 通知対象物質　　　☐（不純物でも対象）
```

![不純物種別の画面。上で種別を選び、下で非該当にする規制区分にチェックを付けます](images/overview/impurity-types.png)

*不純物種別の画面。上で種別を選び、下で非該当にする規制区分にチェックを付けます*

- 不純物として入る物質は、主成分として使うものとは**別の物質として登録**します
  （同じ CAS 番号の物質を仕入先ごとに分けるのと同じ扱いです）
- 除外に当たった物質は**閾値と比べずに非該当**になり、判定には
  **「不純物のため非該当」**とその CAS 番号・含有率が残ります。黙って消しません
- 同じ CAS 番号でも**種別が違えば別々に数えます。**
  主成分 3%、不純物 40% なら、除外した区分では 3% だけで判定します
- 法律の行にチェックを付ければ、その法律の区分をまとめて設定できます。
  区分ごとの「例外」から、**法文物質名単位で上書き**もできます
  （区分は除外しないがこの法文物質名は除外、その逆も）
- 物質のスコアは、その種別で除外される区分の点を数えません
- 除外の設定や物質の種別を変えると「要再計算」の印が出ます。製品の「再計算」を押せば、
  組成を保存し直さなくても新しい種別で判定し直されます

![不純物のため非該当。ホルムアルデヒドを不純物として登録し、安衛法の区分を除外した製品。安衛法の各区分は閾値と比べずに非該当になり、その理由と CAS 番号が残ります。除外していない化審法は該当のままです](images/overview/impurity-judgement.png)

*不純物のため非該当。ホルムアルデヒドを不純物として登録し、安衛法の区分を除外した製品。安衛法の各区分は閾値と比べずに非該当になり、その理由と CAS 番号が残ります。除外していない化審法は該当のままです*

はじめから**「0 不純物ではない」と「1 不純物」**が入っています。ふつうは 1 つで足ります。
該非の決まりかたが違う不純物があるときに、種別を増やしてください。

### 5-5. 「要確認」と「警告」

判定は必ず該当・非該当を答えますが、**それだけでは決められない事情**があるときに印が付きます。

| 印 | 意味 |
| --- | --- |
| 要確認（赤） | 人が見ないと決められない。中身を確かめて「確認する」を押します |
| 警告（灰） | 判定は出ているが、気を付けることがある |

要確認が出る主な場合は次のとおりです。

- **適用条件が書かれている法文物質名**（用途・剤型・製品の種類で決まるもの）。
  濃度だけでは決められないので、必ず人の目を通します。理由の欄には
  **その条文そのもの**が出ます（例: 毒劇法の劇物のバリウム化合物なら
  「適用条件「ただし、次に掲げるものを除く。 イ … ロ 硫酸バリウム」」）。
  何を確かめればよいかが、判定の画面でそのまま読めます
- 総称（「〜及びその化合物」）から広げた CAS で当たった場合

### 5-6. 判定対象日

**判定は必ず判定対象日を持ちます。** 組成を保存したときの自動の判定は今日、
「再計算」では日付を選べます（既定は今日）。選んだ日に効いている規制区分・法文物質名で判定し、
その日付が判定に残ります。施行前・適用終了のものは該当に数えず、「施行前（日付 から）」
「適用終了（日付 まで）」の印付きの非該当として出ます。帳票や PRTR の集計には載せません。
日が経って施行日・適用終了日を跨いだ判定には「要再計算」が付きます。

### 5-7. 人の判断を残せます（判定修正）

自動判定の結果を人が直した場合、その判断を記録します。

- 誰がいつ、どういう理由で直したのかが残ります
- **法規制バージョンを上げても、前提が変わっていなければ判断を引き継ぎます。**
  前提（結び付き・閾値・金属換算係数・組成）が変わった場合は、引き継がずに再確認を求めます

### 5-8. CAS 番号・物質名からの逆引き

判定は「製品 → 法律」の向きですが、含有調査の回答では**「この物質 → どの法律に当たるか」**の
向きで調べたくなります。法律の一覧と法文物質名の一覧に、その欄があります。

```
  手元にある情報　　　　　　　　　　　分かること

   CAS 番号　50-00-0　─────▶　法律　　安衛法 ／ 化管法 ／ 大気汚染防止法 …（15 の法律）
   または　　　　　　　　　　　　　　　規制区分　表示対象物質 ／ 第1種指定化学物質 …（26 の区分）
   物質名　「ホルムアルデヒド」　　　　法文物質名　ホルムアルデヒド（則別表第2の…）
```

- CAS 番号は複数まとめて打てて、「いずれか」「すべて」を選べます。番号は完全一致で見ます
- 物質名は、登録してある物質の名称と別名から探します。**当たる件数に上限はありません。**
  「酸」のように広く当たる言葉でも、取りこぼしなく出ます
- 当たった法律は自動で開き、当たった区分だけが並びます。区分の下の分類も**当たったものだけ**です
  （トルエンで絞れば、安衛法の有機則は第 2 種有機溶剤等だけが出ます）
- 分類のコードを押すと、その分類を選んだ状態で法文物質名の一覧が開きます。そこから規制対象 CAS へ
  たどれます

![法律の一覧を「結び付いた CAS 番号 = 50-00-0」で絞ったところ。該当する法律だけが開き、該当する規制区分だけが並びます](images/overview/laws-reverse-lookup.png)

*法律の一覧を「結び付いた CAS 番号 = 50-00-0」で絞ったところ。該当する法律だけが開き、該当する規制区分だけが並びます*

### 5-9. 物質のスコアとランク

物質が当たっている規制区分の点数を合計した「スコア」と、それを段階に読み替えた「ランク」を
自動で計算します。**規制の厳しい物質を一覧で並べ替える**ための値です。
法律を 1 つずつ見なくても、代替や削減を検討する物質を、厳しいものから順に当たれます。
区分ごとの点数は、お客様の基準で設定できます。

### 5-10. 判定のやり直しは 3 段階

判定結果は保存してあり、前提が変わったときに計算し直します。**全部をやり直さなくても済む**ように、
3 つの粒度を用意しています。

| 粒度 | いつ | 誰が |
| --- | --- | --- |
| その製品と、それを使う親製品 | 組成を保存したとき、自動で | 組成を直した人 |
| 選んだ製品だけ（一覧の「再計算」、または製品の詳細の「再計算」） | データソース・閾値・不純物種別を変えたあと、手元の製品を先に確かめたいとき。製品の詳細では、判定が古いときだけボタンが出ます | 製品を編集できる人 |
| 全製品（システム設定の「全製品の再計算」） | 版の切り替えなど、前提が広く変わったとき | 管理者 |

前提（結び付き・閾値・データソースの有効／無効・金属換算係数・不純物種別）が変わると、画面に
「要再計算」の印が出て、まだ古い前提の判定が残っていることが分かります。
どの段階の再計算も**原材料の展開からやり直す**ので、物質の不純物種別を変えたあとに
組成を保存し直す必要はありません。

## 7. 公開までの流れ（承認）

登録したデータをいきなり全員に見せない、という運用ができます。

```
  ［作成中］
     │ 申請する
     ▼
  ［承認待］ ──── 却下 ────▶［作成中］へ戻る
     │ 承認する              （取り下げても戻る）
     ▼
  ［公開済］ ──── 公開の取りやめ ────▶［作成中］へ戻る
```

| 状態 | 意味 |
| --- | --- |
| 作成中 | 書いている途中。本人と権限のある人だけに見えます |
| 承認待 | 申請済み。誰も直せません |
| 却下 | 差し戻し。直して再申請できます |
| 公開済 | 全員が使えます |

- **承認を要るか要らないかは、物質・製品それぞれで設定できます**
- 申請・承認・却下・取り下げの履歴が残り、**誰がいつ判断したか**を後から追えます
- 未公開のものは、他の人の組成の候補にも出ません

## 8. 権限

**役職ではなく、できること単位で決めます。**「部長だから見られる」ではなく
「この人は判定結果を見られる／この人は編集もできる」という持ち方です。

- 権限は 22 種類に分かれています（物質を見る／編集する、法規制を編集する、
  ドキュメントを作る／開く、データを取り込む、システム設定、など）
- **よく使う組み合わせをプリセット**として用意しています（閲覧のみ、担当者、管理者など）
- 権限どうしの依存関係（これを付けるならこれも要る）は自動で補います
- **機密の扱いはサーバー側で行います。**見えない製品・組成は、画面で隠すのではなく
  そもそも送りません。TSV 書き出しや帳票に出すときも同じ扱いです
- 非公開の組成を持つ製品、未公開の物質は、権限のない人には存在ごと見えません

## 9. セキュリティ

- 重要な操作は監査ログに残ります
- 接続元（IP アドレス）による制限のしくみが入っています。
  どこから使われているかを記録している段階で、実際に遮断する運用はこれからです

## 10. 毎日使うための使い勝手

## 13. いまは対象外のこと

導入判断に関わるため、**できないこともそのまま書きます。**
自動で決められないものは、黙って非該当にせず「要確認」として人に渡す、という作りです。

- **用途や剤型で決まる規制**（RoHS 附属書 III の適用除外、K-REACH の用途条件、
  第一種特定化学物質の使用用途など）は、自動判定していません。
  該当し得るものには「要確認」を立て、条文を読んで判断していただく形です
- **不純物の除外に付く濃度の条件**（POPs 規則の非意図的微量汚染物質など、
  「この濃度以下なら非該当」という決まりかた）は、システムが濃度を見て判断しません。
  その濃度以下で入るものを不純物の種別にする、という運用で表していただきます
- **インベントリへの収載／非収載を使った判定**は、まだ入っていません（番号の表示までです）
- **年度ごとの判定の組の保存**（PRTR の届出のように、年度の基準日で全製品を判定して確認した結果を
  年度ごとに残す）はこれからです。判定対象日を選んだ再計算はできます
- 未収録の法規制（EU POPs 規則の一部・台湾・米国 Prop65 の詳細など）は、
  外部データベースに一覧があるため、ご要望に応じて追加できます

## 14. 導入から日々の運用まで

1. 物質と製品（組成）を登録します。既存データはファイルで取り込めます
2. 規制データの版と、資料の優先順位を決めます
3. 判定を実行します。以後、組成を直すたびに自動で判定し直します
4. 「要確認」が付いたものを人が確認し、判断を残します
5. 取引先への回答や社内報告を、自社様式の帳票で出します
6. 規制が改正されたら新しい版を取り込み、**前の版との差分**を見て、影響のある製品を洗います。
   洗い出した製品は一覧で選んで判定し直し、全製品のやり直しは落ち着いてから行います
7. 取引先から含有調査が来たら、CAS 番号や物質名から**どの法律のどの区分に当たるか**を逆引きし、
   自社様式の回答書を出します

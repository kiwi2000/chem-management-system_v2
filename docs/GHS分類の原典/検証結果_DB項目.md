### 検証で分かった、設計に効く事実

1. **GHS 改訂版は「出どころ×版」の属性では足りない。** NITE 統合版は「物質ごとの最新結果」だが、項目ごとに分類した年度が違い、初版〜6 版のガイダンスが混在している（根拠一覧 117,026 行のうち GHS 初版が 22,459 行、6 版が 25,075 行）。**改訂版は分類の行（クラスごと）に持つ**必要がある
2. **「載っていない」の意味が国で違う。** NITE は全項目に値がある（分類できない／該当しない／対象外を区別）。EU は調和された項目だけ載り、無い項目は「未評価」。**状態の列を持ち、「未評価」を第 4 の値として足す**
3. **H コードは NITE・中国には無い。** クラス×区分から H を引くカタログが要る（韓国・EU・豪州の値と突き合わせて作れる。豪州の `hcis_ghs_hazardcatalog.xlsx` 571 行がそのまま素材になる）
4. **SCL・M・ATE を構造で持っているのは韓国の M 係数だけ。** EU/GB は文字列なので取り込み時に解析する（`Skin Corr. 1A; H314: C ≥ 15 %` の形。範囲・単位・小数点コンマ）。解析できなかったものは原文のまま残す列が要る
5. **適用開始日は EU だけが行で持つ。** NITE は年度、韓国・中国は文書の施行日、豪州は無し。**「公表（取り込み）」の記録が日付の既定値を供給し、行に法的な日付があればそれで上書き**、という前回の案で足りる
6. **差分の配られ方は 3 通り。** NITE＝差分＋正誤表、EU＝ATP ごと（行に From）、韓国・英国＝丸ごと差し替え、中国＝通知ごとの追加修正。前回の「全件の写し／差分」の 2 モードで吸収できる
7. **濃度条件つきの行は全部の国にある。** ただし表し方が違う（枝番、名前の %、SCL の範囲、続き行）。**条件の列（濃度の下限・上限・物理形態）を行に持ち、取り込み時に各国の書き方から起こす**
8. **複数 CAS・CAS 無し（グループ項目）は EU に多い**（153＋580 項目）。EU の項目は Index 番号が主キーで、CAS は 0〜n 個。**「項目」と「CAS の突き合わせ」を別の表にする**（ECHA CHEM の Association List が「グループ項目→構成物質」の展開を配っているが 10,000 件で打ち切られる）
9. **削除された項目**が官報の XML には残る（24 項目）。取り込みで「削除」を扱えるように（適用終了日を入れる）
10. **ECHA CHEM と官報で載っている項目が食い違う**（ECHA CHEM にだけ 25、官報にだけ 4）。同じ出どころでも配布経路で差が出るので、**公表の記録に「経路（ファイル名・URL・取得日）」を残す**

### 4-7. カタログ（システム共通）

- **クラス・区分のカタログ**: 共通コード × 各 GHS 改訂版での有無 × 各国表記（日本語・英語略号・韓国語・中国語）。豪州の `hcis_ghs_hazardcatalog.xlsx`（571 行: 略号 → H コード → 英文）が出発点になる
- **H/P 文のカタログ**: コード × 言語 × 国の公式訳（前回の案のまま）
- **改訂版の読み替え表**: 旧区分 → 新区分（例: 可燃性ガス 1 → 1A/1B）

### 4-8. 物質ごとの上書き（前回の③）

`sds_ghs_overrides`: substance_id × hazard_class × category × status × h_codes × reason × decided_by/at × review_required（出どころの版が変わったら立てる）。列の形は 4-5 と同じにして、計算時に 4-5 の上に重ねる。

## 6. 未確認・要判断

1. **NITE の利用条件**: 「ラベル・SDS 作成時の引用・複写は自由」とあるが、製品に組み込んで配布することの可否は明文がない。NITE に確認するか、お客さん側で各自ダウンロードして取り込む運用（システムは取り込み口だけ持つ）にするか
2. **ECHA の「実質的部分の複製には書面許可」**: 4,400 項目の全件を製品に同梱するのは該当し得る。官報（CC BY 4.0）の XML から取る経路なら問題ない。**EU は官報の Formex を主、ECHA CHEM を補助**にする
3. **豪州 HCIS**: 政府全体は CC BY 4.0 だが HCIS の画面は「All rights reserved」。組み込み前に確認
4. **中国の分類情報表**は 2015 年版のまま（通知で追加・修正）。GB 30000 系の改訂版番号は書かれていない
5. **台湾・NZ は一括データが無い**ので、取り込みの仕組みは後回し（台湾の 2016 年一覧は「参考用・商業利用不可」の但し書きがあるので、利用条件として記録）
6. 上の表の列は「必要な情報」を並べたもので、**表の分け方（4-3〜4-6）は実装時に見直す**

## 7. 前回の設計との照合

- 「CAS 単位で適用開始日を付けて足す・古い行は残す・載っていない CAS は触らない」→ NITE の差分配布・EU の From で成り立つ。**ただし単位は「CAS」ではなく「出どころの項目」**（EU は Index 番号、CAS は 0〜n 個）。CAS は突き合わせの表で持つ
- 「版はスナップショットにしない」→ 韓国・英国は丸ごと配られるので、取り込みで差分を出す動きが要る（前回の「全件の写し」モード）
- 「GHS 改訂版は出どころ×版の属性」→ **修正: 分類の行ごとに持つ**（NITE で混在するため）
- 「原典を主、LOLI は展開の補助」→ EU のグループ項目（CAS 無し 580）に対して、ECHA CHEM の Association List が構成物質の展開を配っている（10,000 件打ち切り）。LOLI が無くても部分的に展開できる

## 8. 官報 XML から起こした附属書VI の表は正しいか（突き合わせ）

官報（EU 出版局の Formex XML、2026-05-01 適用の統合版）から起こした表を、独立した 2 つの原典と Index 番号で突き合わせた。
比べたのは 分類（クラス×区分）・H コード・濃度限界等の文字列・Notes。並び順・空白・小数点の書式・最小分類の `*` は無視。

| 相手 | 突き合わせた項目数 | 分類が違う | 原因の内訳 |
| --- | --- | --- | --- |
| 英国 HSE GB MCL（公式 Excel） | 4,414 | 43 | 英国の独自判断・未採用（ATP23 未反映、Note 11 未採用）、官報の表記揺れ |
| ECHA CHEM Export | 4,416 | 28 | **ATP23（2027-02-01 適用）が ECHA CHEM には既に載っている**（統合版はまだ）、官報の表記揺れ（`Skin. Corr.`、`Muta 2`、`Unst. Expl`、`Carc. 1a`）、ECHA と官報の実質的な食い違い |

疑わしかった 3 件は官報の XML を直接読んで確かめた。**いずれも変換は官報どおり**で、違いは官報側の記述だった。

| Index | 気になった点 | 官報の XML |
| --- | --- | --- |
| 009-007-00-3 | 濃度限界が `0,1 % ≤ C < %`（`1` が無い） | 官報の本文がそのまま `≤ C < %`。**官報の誤植**（英国版は `< 1 %`） |
| 005-005-00-1 ほかホウ素化合物 6 件 | Notes に `11` | 官報の Notes 欄が `11`（2024/2564 で足された Note 11）。英国は未採用で空 |
| 006-014-00-3 nabam | 分類の H に `H400` が無い | 官報の H 欄が `H302 H335 H317 H410`（クラス欄には Aquatic Acute 1 がある）。英国版は H400 あり |

ほかに、ECHA CHEM と官報で**実質的に違う**もの: 602-091-00-8 は ECHA CHEM に `Aquatic Chronic 2` があり官報の統合版には無い。

### 結論

- **変換は信用してよい**（官報の文字を落としていない）。ただし「官報どおり」であって「正しい」とは限らず、**官報自体に誤植と表記揺れがある**
- **ECHA CHEM の Export は「将来の ATP を含む最新」を 1 行で出す**（`To` が無い）。2027-02-01 適用の ATP23 の値が、いまの値として出ている。適用日で引くには官報の統合版（適用日ごとに出る）か、ATP ごとの差分が要る
- 設計への反映: 分類の行に **`raw_text`（原文のまま）を必ず残す**、取り込み時の正規化は表記揺れ（`Skin. Corr.` → `Skin Corr.`、`Muta 2` → `Muta. 2`、`1a` → `1A`）を辞書で吸収する、**複数の経路（官報・ECHA CHEM・英国）を突き合わせて食い違いを「要確認」一覧に出す**取り込みが要る

## 9. 手作業で取る場合（人がブラウザで）

自動取得は ECHA 本家（echa.europa.eu）と EUR-Lex が弾いた。人がブラウザで開けば取れるはずのもの:

1. **ECHA「Annex VI to CLP」ページの Export**（https://echa.europa.eu/information-on-chemicals/annex-vi-to-clp）: 調和分類の表を Excel/CSV で出せる（濃度限界・M・ATE・Notes を含む列があるはず）。当方の官報変換と突き合わせる材料になる。**ただしこのページの現在の有無は WAF で確認できていない**
2. **ECHA CHEM の Export ボタン**（https://chem.echa.europa.eu/ → CLP Annex VI harmonised classifications）: 当方が API 経由で取ったものと同じ（8 列、濃度限界等は無い）
3. **ECHA の法的告知**（https://echa.europa.eu/legal-notice）: 「実質的部分の複製には書面許可」の原文確認
4. EUR-Lex の CLP 統合版（HTML/PDF）: 当方は出版局から同じものを取れているので不要

### 8-2. ECHA 配布の Excel（人がブラウザで取得、2026-09-27）との突き合わせ

`EU_CLP附属書VI/annex_vi_clp_table_atp23_en.xlsx`（ECHA の「Table of harmonised entries in Annex VI to CLP」ページから）。
**これまでの EU の材料で最も情報が多い**: 16 列（Index / ATP / CELEX / 名前 / EC / CAS / クラス・区分 / 分類 H / 絵表示・信号語 /
表示 H / EUH / **M, SCL, ATE** / Notes / Comment / **In application（適用日）** / EUR-Lex リンク）。
シート `ATP23` が現行 4,441 項目、シート **`History`** が 6,281 行で、Index ごとに CLP 原文からの**全ての版**（ATP・CELEX・適用日つき）を持つ
（4,470 の Index のうち 1,194 が 2 版以上。最大 5 版）。`Comment` 列（3,126 行）に ECHA が加えた訂正の記録（クラスの並び順の統一など）。

| 比べたもの | 結果 |
| --- | --- |
| 官報変換 vs ECHA Excel（ATP23 の将来行 32 件を除く） | クラス 11 件・H 3 件・Notes 1 件が違う。**全部、官報側の表記揺れか誤植**（`Self-heat 1`、`Unst. Expl`、`Flam. Gas. 1`、`Carc. 1Β`＝ギリシャ文字のベータ、H270/H201 が ECHA では H260/H200、nabam の H400 抜け）と、実質的な食い違い 1 件（602-091-00-8 の Aquatic Chronic 2 が官報に無い）。濃度限界等の 278 件は `1 %` と `1.0 %` などの書式差 |
| 載っている項目 | ECHA にだけ 25（ATP23 の 22 ＋ **ATP22 の 005-022-00-4・606-156-00-1 が官報の統合版 0501・0701 のどちらにも無い** ＋ 649-282-00-2）、官報にだけ 4（二酸化チタン 022-006-00-2 ほか） |
| 適用日 | ECHA Excel は行ごとに `In application` を持ち、`History` で過去の版も引ける。ECHA CHEM の Export（`To` 無し）より設計に合う |

**ECHA の法的告知（原文は `EU_CLP附属書VI/_ECHA_Legal_Notice_v10_2026-06-04.md`、Version 10・2026-06-04）**:
一般規則では出典明記で商用利用も可だが、**「データベースの全部または実質的部分」の複製は書面許可が要る**。さらに **CAS 番号の情報は
American Chemical Society の財産で、法令上の要求・法定の報告書作成以外の利用・再配布には ACS の書面許可が要る**。
法的効力を持つのは官報の条文だけ（附属書VI は ECHA が「真正版」として公表する一覧に入っていない）。
→ 附属書VI 4,400 項目を ECHA から丸ごと取ると「実質的部分」に当たり得る。**同じ内容が官報（CC BY 4.0）からも取れる**ので、
条件を気にするお客さんには官報経由を選べるようにしておく。CAS の条項は官報経由でも意識しておく（法令対応の目的であることを、製品の説明に明記する）。

**利用条件（Excel 先頭の Disclaimer）**: 「informative purposes not including commercial activities or reproduction」＝**商用利用・複製は不可**。
出どころの利用条件として記録する。取り込むかはお客さんの判断（自社環境では取り込む）。
ECHA が `Comment` に残している訂正（誤植の修正・並び順）は、官報から取り込むときの正規化辞書の根拠になる。

### 8-3. EU の取り込みの方針（検証を踏まえて）

1. EU の出どころは **官報の Formex XML**（出版局 CELLAR。適用日ごとの統合版。CC BY 4.0）と **ECHA の Excel**（`History` シートに全版と適用日。利用条件あり）の 2 経路を持つ。どちらを使うかはお客さんの利用条件で選ぶ。自社環境では両方取り込む
2. 適用開始日は、統合版の「適用日」と、行の `CLG.MDFO ACTIVE.DOC`（どの改正規則で置き換わったか）から。将来の ATP は、その ATP の官報を別に取り込む
3. 官報の表記揺れ・誤植は**辞書で正規化し、原文を `raw_text` に残す**。ECHA の Excel／ECHA CHEM と突き合わせて食い違う項目は「要確認」に出す（今回見つかった 602-091-00-8、009-017-00-8、609-010-00-5、nabam、ATP22 の 2 件など）
4. ECHA の Excel は ECHA 本家サイトから人がブラウザで取る（自動取得は WAF が弾く）。取り込みは他と同じ「公表（取り込み）」の記録で行う

# 第1部 システム共通

## 1.1 概要・起動
- 化学物質・製品組成・法規制を一元管理し、製品の規制該当を**根拠付きで自動判定**するWebアプリ
- 起動: `docker compose up -d`（DB）→ `npm run dev` → http://localhost:3000
- 技術: Next.js（画面とAPI一体）/ PostgreSQL（ローカルDocker、MySQL・SQL Serverへ切替可能な設計）/ 認証はSupabase（認証のみ。業務データはローカルDB）
- 検証コマンド: `npm test`（ユニット36件）／`npx tsx scripts/e2e-judgment-test.ts`（実DB回帰）／`npx tsx scripts/seed-test-data.ts`（テストデータ投入）

## 1.2 ロールと編集権限
| ロール | 業務データ | 全製品・全組成の閲覧 | 公開フラグ設定 | テンプレート登録 | ユーザー管理・システム設定 |
|---|---|---|---|---|---|
| システム管理者 | 全操作 | ○ | ○ | ○ | ○ |
| 特権ユーザー | 全操作 | ○ | ○ | ○ | × |
| 非特権ユーザー | 制限付き（下記） | ×（マスキング） | × | × | × |

- **編集権限**（ロールと独立）: 管理者・特権＝常に可。非特権＝管理者が「可/不可」を設定
- **編集不可の人ができること**: 参照・検索・判定実行・判定履歴閲覧・TSVダウンロード・ドキュメント生成
- **編集不可の人の画面**: 「＋新規登録」「削除」「複製」等のボタンが消える。一覧の「編集」は「表示」表記になる。フォームは入力欄がグレーアウトし保存ボタンが消え、上部に青い注記「参照のみ: 編集権限がないため、登録・変更・削除はできません（判定実行とダウンロードは可能です）」が出る
- 認可は**サーバ側で強制**（ボタンを隠すのは補助。直接APIを叩いても401/403で拒否される）

## 1.3 ログイン・ユーザー登録の流れ
1. 管理者が Supabase Dashboard（Authentication→Users→Add user）でメール＋パスワードを作成（**Auto Confirm User にチェック**）
2. 本人がアプリにログインした瞬間、アプリの users に自動登録される
   - **最初にログインした人＝システム管理者**（編集可）
   - 2人目以降＝非特権・編集不可（管理者が /admin で昇格させる）
3. 無効化されたユーザーはログインしても全APIで401になる

## 1.4 機密の制御（製品の2フラグ）
| フラグ | 既定 | オンの効果（非特権ユーザーに対して） |
|---|---|---|
| 非公開フラグ | オフ＝公開 | 製品が**丸ごと見えない**（一覧・検索・詳細404・逆引き・TSV出力・組成の原材料候補からも除外） |
| 組成公開フラグ | オフ＝非開示 | オンにすると組成を**開示**する |

組成非開示（既定）の製品を非特権ユーザーが見た場合:
- 製品編集画面に組成エディタの代わりに注記「この製品の組成は非開示です（組成公開フラグがオフのため、特権ユーザーのみ閲覧・編集できます）」
- 展開の実行は403「この製品の組成は非開示です」
- 判定は実行できる。**結論（該当/非該当）と算定値は見える**が寄与明細は空になり、注記「組成が非開示のため、寄与物質の明細は表示されません（結論のみ表示）」
- 逆引き（この物質を含む製品）では含有率が「（非開示）」表示
- ドキュメント生成では composition が空・`{masked}` タグに「（組成非開示）」が入る

## 1.5 画面共通の部品・挙動
- **ヘッダー**（ログイン時のみ表示）: 左からロゴ「化学物質管理システム」（クリックでホーム）／ナビ「物質・製品・法規制・リンク・金属換算・取込/出力」＋管理者のみ「管理」／右側にユーザー名（メール）・ロールバッジ・編集不可なら「参照のみ」バッジ・言語切替セレクト（有効ロケールが2つ以上のときだけ表示。「（既定）」＋ロケール表示名）・「ログアウト」ボタン
- **未ログイン**: すべてのページが /login へリダイレクト（307）。ログイン済みで /login を開くとホームへ
- **一覧の共通挙動**: 検索欄＋「検索」ボタン（Enterでも実行）。部分一致・大文字小文字は区別しない（コード・CASは正規化して突合）。ページングは**50件/ページ**、下部に「全 N 件」「X / Y」「前へ」「次へ」
- **削除の共通挙動**: ブラウザの確認ダイアログ→OK で削除（論理削除）。参照されているデータは一度目の削除がエラー（参照件数入りメッセージ）になり、**もう一度確認ダイアログが出て OK すると強制削除**（force）
- **主なエラーメッセージ**: 未ログイン=「ログインが必要です」／編集権限なし=「編集権限がありません（参照・判定実行・ダウンロードのみ可能です）」／管理者専用=「システム管理者のみ実行できます」／コード重複=「〜は既に使用されています」（409）
- 監査ログ: すべての登録・変更・削除・判定・取込・生成を記録（誰が・いつ・何を。画面は未提供）

## 1.6 ログイン画面（/login）
- 中央カード「化学物質管理システム／アカウントでログインしてください」
- 入力: メールアドレス（必須）／パスワード（必須）
- ボタン: 「ログイン」（処理中は「ログイン中...」）
- 失敗時: 赤い注記「メールアドレスまたはパスワードが正しくありません」（アカウントの有無は開示しない）

## 1.7 ホーム（/）
- 見出し「ホーム」
- メニューカード8枚（クリックで遷移）: 物質マスタ／製品・原材料／法規制マスタ／リンク管理／金属換算係数／TSV取込・出力／ドキュメント生成／管理
- 各カードの題・説明は**翻訳キー対応済み**（言語を切り替えると英語表示になる）

# 第2部 マスタ管理画面

## 2.1 物質一覧（/substances）
- 見出し「物質マスタ」、右上「＋ 新規登録」（編集可のみ）
- 検索欄: プレースホルダ「コード / CAS番号 / 名称で検索」（コード・CAS・和名・英名の部分一致）
- 表の列: 物質コード｜CAS番号｜名称（サブ名称があると「（他N件）」を付記）｜英訳｜操作
- 操作: 「編集」（編集不可の人は「表示」）→詳細へ／「削除」（編集可のみ）
- 削除確認:「物質「コード: 名称」を削除しますか？」→ 組成から参照されていると「この物質は N 件の組成から参照されています。削除する場合は force=true を指定してください」→再確認でOKすると削除

## 2.2 物質の登録・編集（/substances/new・/substances/{id}）
**カード「物質の登録／編集」**
| 入力欄 | 必須 | 制限・説明 |
|---|---|---|
| 物質コード | ○ | 最大100字。全物質で一意（重複は409エラー）。例 SUB-000123 |
| CAS番号 | ○ | 最大50字。**重複可**（別物質が同じCASを持てる）。形式チェックは緩い（暫定CAS運用のため） |
| メイン日本語名称 | ○ | 最大500字 |
| 英訳 | − | 最大500字 |

**カード「サブ名称（任意）」**: 行ごとに 日本語名称＋英訳＋「削除」。「＋ サブ名称を追加」で行追加。日本語名称が空の行は保存時に無視
**ボタン**: 「保存」（処理中「保存中...」）／「一覧へ戻る」
- 保存成功: 通常は一覧へ戻る。**同一CASの物質が既にあると**その場に留まり警告「⚠️ 同一CAS番号（X）の物質が既に N 件登録されています」＋「保存しました。」を表示（保存自体は成功）
- 編集画面の下部カード「**この物質を含む製品**（展開済みデータに基づく）」: 列=製品コード｜製品名｜統合後含有率(wt%)｜「開く」。組成非開示の製品は含有率が「（非開示）」。展開を一度も実行していない製品は出ない（注記あり）。最大500件

## 2.3 金属換算係数（/metal-factors）
- 見出し＋説明「PRTR型（金属換算方式）の判定で使用します。寄与 = 含有率 × 係数 ÷ 100。CAS基準の独立マスタです」
- **カード「係数の登録／編集」**（編集可のみ表示）: CAS番号*｜金属元素*（元素記号。大文字1字+小文字0..2字。例 Pb）｜割合(%)*（0より大きく100以下・小数6桁まで）｜「保存」｜編集中のみ「キャンセル」
  - 一覧の「編集」を押すとこのフォームに値が入り画面上部へスクロール
  - 物質マスタに無いCASでも登録可・警告「⚠️ CAS番号「X」は物質マスタに未登録です」
  - 同じCAS×元素は409「…の係数は既に登録されています」（過去に削除した組は自動で復活・上書き）
- 検索欄「CAS / 元素で検索」
- 表: CAS番号｜金属元素｜割合(%)｜操作（編集・削除、編集可のみ）

## 2.4 製品一覧（/products）
- 見出し「製品 / 原材料」、右上「＋ 新規登録」（編集可のみ）
- 検索欄「コード / 名称で検索」
- 表の列: 製品コード｜名称（英名を小さく併記）｜属性（バッジ: 「原材料可」「非公開」「組成公開」）｜操作（編集/表示・削除）
- 非特権ユーザーには非公開製品が一覧に**出ない**
- 削除: 他製品の組成から原材料として参照されていると警告→再確認で強制削除

## 2.5 製品の登録・編集（/products/new・/products/{id}）
**カード「製品の登録／編集」**
| 入力欄 | 必須 | 説明 |
|---|---|---|
| 製品コード | ○ | 最大100字・一意。例 PRD-000123 |
| 日本語名称 | ○ | 最大500字 |
| 英語名称 | − | 最大500字 |
| ☑ 原材料として他製品の組成に使用できる（原材料利用可） | − | 既定オフ。オフに戻すとき参照があれば警告「この製品は N 件の組成から原材料として参照されています（参照は維持されます）」（保存は可能） |
| ☑ 非公開（非特権ユーザーからこの製品を丸ごと隠す） | − | **特権のみ表示・設定可** |
| ☑ 組成を公開（非特権ユーザーにも組成を開示する） | − | **特権のみ表示・設定可** |

- **新規保存すると編集画面へ自動遷移**（続けて組成を入力できる）
- 編集画面の構成: 製品フォーム → 組成エディタ（組成非開示×非特権には注記のみ）→ 展開カード → 判定カード

## 2.6 組成エディタ（製品編集画面内・カード「原組成」）
- 表の列: 種別（バッジ「物質」/「原材料」）｜構成要素（コード｜名称）｜含有率(wt%)入力欄｜balanceチェック｜「削除」
  - **含有率は単一の数値のみ**（範囲・「<1%」・N.D.は不可）。0より大きく100以下・小数6桁まで
  - **balance（残部）**: チェックすると含有率欄が無効になり「自動補完」表示。値は 100%−既知成分合計。**1製品に1行まで**
- 表の下「入力済み合計（参考）: X%」（画面上の目安。正式検証はサーバ）
- **枠「構成要素を追加」**（編集可のみ表示）: 種別セレクト（物質／原材料（製品））＋検索欄「コード / 名称で検索」＋「検索」→候補リスト最大10件→クリックで行追加
  - 原材料の候補は「原材料利用可」オンの製品のみ。**自分自身は候補に出ない**。非特権には非公開製品も出ない
  - 既に追加済みの要素を選ぶと alert「同じ構成要素が既に追加されています」
- **「組成を保存」**: 全行を一括保存（全置換）。成功「保存しました。既知成分合計 X%（・balance Y%）」＋警告表示
- 保存時のエラー（1つでもあると保存されない・複数同時表示）:
  - 「同一の物質（原材料）が複数行に指定されています」
  - 「物質（原材料）が見つかりません」／「「コード」は原材料利用可フラグがオフのため組成に使用できません」
  - 「循環参照が発生するため登録できません（この製品自身に行き着く原材料が含まれています）」
  - 合計検証（システム設定のモードによる。§5.2）: 例「含有率合計が100%を超えています（合計 X%）」
  - balance系: 「balance（残部）行は1製品につき1件までです」「balance行に含有率は指定できません」「balance（残部）行はシステム設定で許可されていません」
- 警告（保存はされる）: 標準モードで合計<100%「含有率合計が100%未満です（合計 X%・未開示/残部あり）」／組成が空「組成が空です」

## 2.7 展開・統合（カード「展開・統合組成（物質レベル）」）
- 「展開を実行」ボタン（組成を閲覧できる人なら誰でも可）
- 計算: 原材料を再帰的に物質まで分解。**寄与率＝親含有率×子含有率÷100**（多段は繰り返し）。同一物質は合算統合。経路明細も保存
- balance行は展開時に 100−既知合計 で評価。既知合計が100超なら0に切り詰めて警告
- 結果表: 物質コード｜CAS番号｜名称｜統合後含有率(wt%)（小数12桁まで）
- 警告（内部コード形式で表示）: `composition-missing: product=…`（原材料の組成未登録）／`cycle-detected: …`／`max-depth-exceeded: …`（50階層超）
- 結果はDBに保存され、逆引き・ドキュメント生成が参照する

# 第3部 判定

## 3.1 判定カード（製品編集画面内・カード「規制該当判定」）
- 「使用リンクバージョン」セレクト: 全バージョンを表示。「（有効）」「（廃止）」を付記。**初期選択は有効(ACTIVE)の版**（無ければ先頭）
- 「判定を実行」ボタン（**編集権限がなくても実行可**。バージョン未選択時は無効）
- 実行時の内部動作: ①最新組成で展開し直す→②選択版のリンクで判定→③結果を根拠付きで保存

## 3.2 判定のルール（適用順）
1. **リンク解決**: 展開後の各物質のCASを、選択バージョン内の「法文物質名↔CAS」リンクと突合。**情報源は優先度の小さい順**に探索し、その法文物質名のリンクを最初に持っていた情報源**だけ**を採用（フォールバック。法文物質名ごとに判断）。無効の情報源は使わない
2. **寄与量**: 含有率方式＝統合後含有率そのもの。金属換算方式＝含有率×金属換算係数÷100（係数はCAS×判定金属元素で係数マスタから取得。**未登録なら寄与0**＋警告 `metal-factor-missing: …`）
3. **閾値**: 法文物質名に該当含有率範囲があればそれを、無ければ規制区分の閾値を使用。**該当＝下限≦値（上限があれば ≦上限）**。上限超過はその区分では非該当（濃度帯を分ける規制用）。境界は「以上・以下」（含む）
4. **合算方式**（区分の設定・3択）:
   - **法文物質名単位合算**: 名称ごとに該当物質の寄与を合算→閾値比較。いずれかの名称が該当すれば区分該当。同一物質が複数名称に該当すれば各名称で計上（重複可）
   - **区分全体合算**: 区分内の該当物質を**1物質1回だけ**合算→区分閾値と比較
   - **合算なし**: 物質ごとに個別判定。1つでも該当すれば区分該当
5. **兼ね合い（累積）**: 兼ね合いフラグがオンの区分は、同じ兼ね合いグループ内で自分以下のrank（小さい=厳しい）の区分の該当物質を**プールして合算**（同一物質1回）し、自区分の区分閾値と比較。例: 3種判定＝1種+2種+3種物質の合計。オフ（既定）の区分は独立判定
6. **結果抑制**: 兼ね合いグループ内で複数区分が該当したら、**rank最小の区分だけが「最終該当」**。他は「抑制」マーク（記録は残る）。グループ外の区分は該当＝そのまま最終該当

## 3.3 判定結果の表示
- 緑の帯「判定完了（バージョン X）。最終該当区分: 化審法／第一種… 」（無ければ「なし（すべて非該当）」）
- 警告一覧（廃止版で実行「廃止済みのバージョン（X）で判定を実行しています」・係数欠落・組成未登録など）
- 結果表の列: 法律（略称）｜規制区分｜該当（赤バッジ「該当」/白「非該当」）｜算定値(wt%)（小数6桁）｜結果（赤「最終該当」/白「抑制（上位区分が該当）」）
- 規制区分セルの「根拠（寄与物質 N 件）」を開くと: `コード（CAS）名称 → 寄与 X%／管理番号 名称／情報源: LOLI` の明細
- **判定履歴**（同カード下部・最新20件）: 実行日時｜バージョン｜最終該当区分｜「表示」（過去の保存結果を上の結果表に再表示。履歴の根拠明細には法文物質名は出ない）

# 第4部 法規制・リンク

## 4.1 法規制一覧（/laws）
- 見出し「法規制マスタ」、右上「＋ 法律を登録」（編集可のみ）
- 検索欄「コード / 法律名 / 略称で検索」
- 表: 法律コード｜法律名（英併記）｜略称｜操作（編集/表示・削除）
- 削除: 配下に区分があると警告「この法律には N 件の規制区分があります。…」→強制可

## 4.2 法律の登録・編集（/laws/new・/laws/{id}）

**カード「規制区分」**（編集画面のみ）: 右上「＋ 区分を追加」（編集可のみ）
- 表: 区分コード｜区分名｜合算方式｜兼ね合い（バッジ「rank N・グループ名」または「独立」）｜区分閾値（「下限 〜 上限」・無し「—」）｜法文物質名 N件｜操作（編集/表示・削除）

## 4.3 規制区分の登録・編集（/laws/{id}/categories/new・/categories/{id}）
- パンくず: 法規制マスタ ＞ 法律名 ＞ 区分名
**カード「規制区分の登録／編集」**
| 入力欄 | 必須 | 説明 |
|---|---|---|
| 区分コード | ○ | 法律内で一意。例 CLASS1 |
| 区分名（日本語） | ○ | 例 第一種特定化学物質 |
| 区分名（英語） | − | |
| 合算方式 | ○ | セレクト: 法文物質名単位合算（最頻）／区分全体合算（同一物質は1回計上）／合算なし（物質ごとに個別判定） |
| 区分閾値 下限/上限 (wt%) | − | 法文物質名側に閾値が無い場合に使用。上限超過は非該当 |
| ☑ 兼ね合い判定を行う | − | 既定オフ。オンにすると下2欄が現れ**必須**になる |
| └ rank | 兼ね合い時○ | 1以上の整数。小さいほど厳しい（例 1種=1） |
| └ 兼ね合いグループ | 兼ね合い時○ | 同一グループ内で累積（例 CSCL-SP） |
| ☑ 結果抑制 | − | 既定オン。複数該当時は最も厳しい区分のみ最終結果 |
- バリデーション: 兼ね合いオンで rank/グループ未入力→「兼ね合いフラグがオンの区分には rank（順位）／兼ね合いグループが必須です」。下限＞上限→「閾値の下限が上限を超えています」
- 新規保存→その区分の編集画面へ遷移。「法律へ戻る」ボタン
**カード「法文物質名（管理番号順）」**: 右上「＋ 追加」（編集可のみ）→インラインフォームが開く
| 入力欄 | 必須 | 説明 |
|---|---|---|
| 管理番号 | ○ | 区分内で一意（重複409） |
| 法文物質名（日本語）/ 英訳 | ○/− | 例 鉛及びその化合物 |
| 閾値 下限/上限 (wt%) | − | プレースホルダ「無ければ区分閾値」「超過は非該当」 |
| 判定方式 | ○ | セレクト: 含有率方式／金属換算方式（PRTR型） |
| 判定金属元素 | 金属換算時○ | 金属換算選択時のみ入力可（例 Pb）。含有率方式で入れるとエラー |
- フォームのボタン: 「保存」「キャンセル」
- 表: 管理番号｜法文物質名（英併記）｜閾値（下限無しは「（区分閾値）」）｜判定方式バッジ（金属換算は「（Pb）」等を付記）｜操作（編集・削除）
- 削除: リンクから参照されていると警告「この法文物質名は N 件のCASリンクから参照されています。…」→強制可

## 4.4 リンクバージョン一覧（/link-versions）

- **カード「新しいバージョンを作成」**（編集可のみ）: バージョンコード*（一意・例 2026Q2）｜名称/説明｜「作成」（作成直後の状態はドラフト）

## 4.5 バージョン詳細（/link-versions/{id}）
- パンくず: リンクバージョン ＞ コード
- **カード「バージョン情報」**: バージョンコード*｜名称/説明｜状態セレクト（（未設定）/ドラフト/有効/廃止）｜「保存」（編集可のみ）。下に統計「リンク合計: N 件／USER: n 件／LOLI: n 件…」
- **カード「リンクの追加（手動登録）」**（編集可のみ）:
  - ① 法文物質名を検索して選択: 検索欄（名称/管理番号）＋「検索」→候補リスト（表記「法律略称／区分名／管理番号 名称」・最大10件）→クリックで「選択中: …」表示
  - ② CAS番号*（例 7439-92-1）
  - ③ 情報源セレクト（「USER（優先度 1）」等。初期選択はUSER）
  - 「リンクを登録」→成功「リンクを登録しました」。CASが物質マスタに無いと追加で警告「⚠️ …（判定では突合されません）」。同一（版×名称×情報源×CAS）は409「同じリンクが既に登録されています」

# 第5部 取込・出力・生成・管理

## 5.1 TSV取込／出力（/import-export）
- 冒頭注記「UTF-8（BOM付き・Excel互換）・タブ区切り・1行目ヘッダ。取込はエラーがあると全件取り込まれません」
- **カード「ダウンロード」**（誰でも可）: ボタン「物質」「製品」「法規制（階層）」「金属換算係数」「リンク」（リンクは横の版セレクトで対象指定）。下段リンク「空テンプレート: 物質・金属換算係数・リンク」
  - 非特権の「製品」出力には非公開製品が**含まれない**
- **カード「一括取込」**（編集可のみ表示）: 対象データセレクト（物質/金属換算係数/リンク）｜（リンク時のみ）取込先バージョンセレクト｜ファイル選択（.tsv/.txt）｜「取込を実行」
  - 成功「取込完了: N 行・新規 X 件・更新 Y 件（・既存スキップ Z 件）」
  - エラー時: 赤い一覧（最大50件）で「N行目: …」形式。**1件でもエラーがあると何も取り込まれない**
  - 取込ルール: 物質＝コードで突合してupsert（既存は更新・サブ名称は全置換）。係数＝CAS×元素でupsert。リンク＝既存と同一の行はスキップして追加のみ。上限10,000行

### TSVの列仕様
| ファイル | 列（順不同・ヘッダ名で判定） |
|---|---|
| 物質 | code, cas_number, name_ja, name_en, sub_names_ja, sub_names_en（サブ名称は `\|` 区切り。和英は位置で対応） |
| 製品（出力のみ） | code, name_ja, name_en, usable_as_material, private_flag, composition_public_flag |
| 法規制（出力のみ） | law_code, law_name_ja, law_abbrev, category_code, category_name_ja, summation_method, rank, interaction_flag, interaction_group, category_threshold_lower, category_threshold_upper, suppress_result_flag, control_number, statutory_name_ja, statutory_name_en, statutory_threshold_lower, statutory_threshold_upper, judgment_method, metal_element（法文物質名1件=1行。階層は列で表現） |
| リンク | law_code, category_code, control_number, cas_number, source_name（版はアップロード時に指定） |
| 金属換算係数 | cas_number, metal_element, ratio_pct |

## 5.2 システム設定（/admin 内・管理者のみ）
| 設定 | 選択肢 | 効果（組成保存・TSV取込に適用） |
|---|---|---|
| 含有率合計の検証モード | 厳格（合計=100%必須）／**標準（既定）**／緩和（検証しない・警告のみ） | 厳格: 100%±ε以外はエラー。標準: 100%＋ε超はエラー・未満は警告。緩和: 100%超も警告のみ |
| 丸め許容誤差 ε (wt%) | 数値（既定 0.01・0〜10） | 合計比較の許容差。入力欄からフォーカスを外すと保存 |
| balance（残部）行の許容 | ☑ on（既定）/off | offにすると balance 行の保存がエラーになる |
- 変更は即時に以後の保存へ適用。既存データを遡ってエラーにはしない

## 5.4 多言語（/admin/locales・管理者のみ）

## 5.5 ドキュメント生成（/doc-templates）
- 冒頭にタグ一覧の説明文
- **カード「テンプレート登録」**（特権のみ機能。非特権が実行すると403）: テンプレート名*｜既定の出力形式セレクト（Word（そのまま）/PDF（要LibreOffice））｜.docxファイル*（**Word .docxのみ・10MB以下**。Excelは未対応）｜「登録」
- **カード「生成対象の製品」**: 検索欄（コード/名称）＋「検索」→候補クリックで「選択中: コード｜名称」
- テンプレート表: 名称｜ファイル名｜操作「Word生成」「PDF生成」「削除」（削除は特権のみ機能）
  - 生成は誰でも可。製品未選択で押すと alert「先に対象製品を選択してください」
  - 生成物のファイル名: `製品コード_テンプレート名.docx / .pdf`（ブラウザでダウンロード）
  - PDFは **LibreOffice がインストールされている場合のみ**（`C:\Program Files\LibreOffice` を自動検出）。無いと「PDF変換には LibreOffice のインストールが必要です（Word形式では生成できます）」
  - タグ記法エラーのテンプレートは「テンプレートの差込に失敗しました（タグの記法を確認してください）」
- 生成履歴はメタ情報のみ保存（ファイル実体は保存しない・都度生成）

# 第6部 データ・計算の共通仕様

- **業務キー**: 物質コード・製品コード・法律コード（一意）／区分コード（法律内一意）／管理番号（区分内一意）／バージョンコード（一意）。コード・CASは**前後空白除去＋大文字化**して突合（後から変更しても内部の紐付けは壊れない）
- **数値**: 含有率・閾値・係数は十進数（Decimal）で計算。浮動小数点誤差なし。保存精度は小数12桁・表示は最大6〜12桁
- **削除**: すべて論理削除（復元はDB操作が必要）。参照チェック→警告→force の2段階
- **判定の再現性**: 判定結果は使用バージョン・情報源優先度のスナップショット・寄与明細とともに保存され、履歴からいつでも再表示できる
- **監査ログ**: users への変更含む全変更操作を記録（entity・action・actor・差分）。閲覧画面は未提供
- **未実装（バックログ）**: 製品・法規制のTSV取込／Excelテンプレート／全画面の翻訳キー化／影響分析・一括判定・要再判定の可視化／整合性チェック画面／監査ログ画面／物質の任意プロパティ（物性・SMILES等）編集画面／添付ファイル

# 管理グループのテスト用データ

管理グループの動きを試すために入れた、見本の組織・管理グループ・メンバー・物質・製品の説明です。
組織管理の仕様 11 章の例を、そのまま形にしてあります。

- 入っている場所: chem.ca-japan.jp と、開発環境
- 目印: コードは全部 `TG-` で始まります。ユーザーのアドレスは `tg-…@example.com` です
- ログイン: テスト用のユーザーにはパスワードを付けていません。「ユーザー管理」の画面で、1 人ずつパスワードを設定してから使います

## 1. 組織

会社が 2 つあります。右の列は、その組織の人を登録するときに「最初に選ばれる管理グループ」です。

| 組織（コード）                 | 上位組織    | 最初に選ばれる管理グループ |
| ------------------------------ | ----------- | -------------------------- |
| **テスト用A社**（TG-A）        | （最上位）  | テスト用A社 全体           |
| 　製造部（TG-A-MFG）           | テスト用A社 | テスト用A社 製造部         |
| 　　第1課（TG-A-MFG1）         | 製造部      | （上の製造部から引き継ぐ） |
| 　開発部（TG-A-DEV）           | テスト用A社 | テスト用A社 開発部         |
| 　品質保証部（TG-A-QA）        | テスト用A社 | テスト用A社 品質保証部     |
| 　営業部（TG-A-SALES）         | テスト用A社 | （上のA社から引き継ぐ）    |
| 　　営業1課（TG-A-SALES1）     | 営業部      | （上のA社から引き継ぐ）    |
| 　総務部（TG-A-GA）            | テスト用A社 | （上のA社から引き継ぐ）    |
| **テスト用B社**（TG-B）        | （最上位）  | テスト用B社 全体           |
| 　開発部（TG-B-DEV）           | テスト用B社 | テスト用B社 開発部         |

## 2. 管理グループ

6 つあります。製品・原材料・物質は、どれか 1 つの管理グループに属します。

| 管理グループ（コード）             | 役どころ                                                           | 表とは別の権限                                                                         |
| ---------------------------------- | ------------------------------------------------------------------ | -------------------------------------------------------------------------------------- |
| テスト用A社 全体（TG-A-ALL）       | A社の人がみんな入る。共通の製品と物質を見るだけ                    | 法規制を見られる                                                                       |
| テスト用A社 製造部（TG-A-MFG）     | 製造部の製品と物質を直せる。組成は見えない                         | データを出力できる、ドキュメントを作れる、ドキュメントを開ける・落とせる               |
| テスト用A社 開発部（TG-A-DEV）     | 開発部の製品・組成・物質を全部直せる                               | 同上                                                                                   |
| テスト用A社 品質保証部（TG-A-QA）  | 承認する。ほかの部の製品と組成を、部ごとに決めた範囲で見る・直す   | 承認できる、データを出力できる、データを取り込める、ドキュメントを作れる、開ける・落とせる |
| テスト用B社 全体（TG-B-ALL）       | B社の人がみんな入る。共通の製品と物質を見るだけ                    | 法規制を見られる                                                                       |
| テスト用B社 開発部（TG-B-DEV）     | B社 開発部の製品と物質を直せる。組成は見えない                     | データを出力できる、ドキュメントを作れる、ドキュメントを開ける・落とせる               |

### 参照・編集できるデータ（表の印）

○ が付いている印です。「編集」を付けると「参照」も付き、「組成 参照」を付けると「製品・原材料 参照」も付きます。

| 管理グループ           | 対象の管理グループ     | 製品・原材料 参照 | 製品・原材料 編集 | 組成 参照 | 組成 編集 | 物質 参照 | 物質 編集 |
| ---------------------- | ---------------------- | :---------------: | :---------------: | :-------: | :-------: | :-------: | :-------: |
| テスト用A社 全体       | テスト用A社 全体       |         ○         |                   |           |           |     ○     |           |
| テスト用A社 製造部     | テスト用A社 製造部     |         ○         |         ○         |           |           |     ○     |     ○     |
| テスト用A社 開発部     | テスト用A社 開発部     |         ○         |         ○         |     ○     |     ○     |     ○     |     ○     |
| テスト用A社 品質保証部 | テスト用A社 品質保証部 |         ○         |         ○         |           |           |     ○     |     ○     |
| 　　〃                 | テスト用A社 全体       |         ○         |         ○         |     ○     |           |     ○     |     ○     |
| 　　〃                 | テスト用A社 製造部     |         ○         |                   |     ○     |     ○     |           |           |
| 　　〃                 | テスト用A社 開発部     |         ○         |                   |     ○     |           |           |           |
| 　　〃                 | テスト用B社 全体       |         ○         |                   |           |           |           |           |
| テスト用B社 全体       | テスト用B社 全体       |         ○         |                   |           |           |     ○     |           |
| テスト用B社 開発部     | テスト用B社 開発部     |         ○         |         ○         |           |           |     ○     |     ○     |

- どの表にも「全体」（もとからある管理グループ）の行はありません。このため、テスト用の人には、もとからある物質と製品は見えません。
- 品質保証部の表が、この見本のいちばんの見どころです。相手の管理グループごとに、できることを変えてあります。

## 5. だれに何が見えるか

「製品」は名称などの製品そのもの、「組成」は中身の表です。書いていないことは、できません。

| 製品                         | 製造             | 開発                                  | 品証                                        | 営業     | B社 開発         |
| ---------------------------- | ---------------- | ------------------------------------- | ------------------------------------------- | -------- | ---------------- |
| TG-MT-A-BASE（A社 全体）     | 製品が見える     | 製品が見える                          | 製品を直せる。組成が見える                  | 製品が見える | 見えない     |
| TG-PR-A-001（A社 全体）      | 製品が見える     | 製品が見える                          | 製品を直せる。組成が見える                  | 製品が見える | 見えない     |
| TG-PR-M-001（製造部）        | 製品を直せる     | 見えない                              | 製品が見える。組成を直せる                  | 見えない | 見えない         |

### 見どころ

- **組成は、中身が全部見えるときだけ見えます。** TG-PR-M-002 は、品証に「組成 参照」の印があっても、中のトルエンとキシレン（製造部の物質）を参照する印が無いので見えません。TG-PR-M-001 は中身が A社 全体の物質だけなので見えます。
- **原材料を含む製品は、原材料の組成も見えることが要ります。** TG-PR-D-002 は開発部の製品ですが、開発の人は共通ベース液（A社 全体）の組成を見られないので、この製品の組成も見えません。品証には見えます。
- **製品を直せることと、組成を直せることは別です。** 製造の人は自分の部の製品を直せますが、組成は見えません。品証は製造部の製品そのものは直せませんが、組成は直せます。
- **公開前のものは、作った本人と承認する人だけに見えます。** 作成中の TG-PR-D-003 は、開発（作った本人）と品証（承認する人）にだけ見えます。直せるのは作った本人だけです。
- **承認待のものは、だれも直せません。** TG-PR-D-004 は、作った本人も、承認する人も、製品も組成も直せません。直すときは、作った本人が申請を取り下げます。品証は承認・却下を試せます。
- **会社をまたぐ参照もできます。** 品証は、B社 全体の製品（TG-PR-B-001）を見られます。B社 開発部の製品（TG-PR-BD-001）は、A社のだれにも見えません。
- **どの管理グループにも入っていない人は、何も見えません。** 総務の人がその例です。

# 管理グループのテスト用データ

管理グループの動きを試すために入れた、見本の組織・管理グループ・メンバー・物質・製品の説明です。
組織管理の仕様 11 章の例を、そのまま形にしてあります。

- 入っている場所: chem.ca-japan.jp と、開発環境
- 目印: コードは全部 `TG-` で始まります。ユーザーのアドレスは `tg-…@example.com` です
- ログイン: テスト用のユーザーにはパスワードを付けていません。「ユーザー管理」の画面で、1 人ずつパスワードを設定してから使います
- 2026-11-22 更新: 2026-11-13 に作ったあとの変更を、6 章にまとめて書き足しました（試しかたつき）

### 見どころ

- **組成は、中身が全部見えるときだけ見えます。** TG-PR-M-002 は、品証に「組成 参照」の印があっても、中のトルエンとキシレン（製造部の物質）を参照する印が無いので見えません。TG-PR-M-001 は中身が A社 全体の物質だけなので見えます。
- **原材料を含む製品は、原材料の組成も見えることが要ります。** TG-PR-D-002 は開発部の製品ですが、開発の人は共通ベース液（A社 全体）の組成を見られないので、この製品の組成も見えません。品証には見えます。
- **製品を直せることと、組成を直せることは別です。** 製造の人は自分の部の製品を直せますが、組成は見えません。品証は製造部の製品そのものは直せませんが、組成は直せます。
- **公開前のものは、作った本人と承認する人だけに見えます。** 作成中の TG-PR-D-003 は、開発（作った本人）と品証（承認する人）にだけ見えます。直せるのは作った本人だけです。
- **承認待のものは、だれも直せません。** TG-PR-D-004 は、作った本人も、承認する人も、製品も組成も直せません。直すときは、作った本人が申請を取り下げます。品証は承認・却下を試せます。データ入出力の取り込みでも、管理グループの変更でも同じです（6 章の 3）。
- **会社をまたぐ参照もできます。** 品証は、B社 全体の製品（TG-PR-B-001）を見られます。B社 開発部の製品（TG-PR-BD-001）は、A社のだれにも見えません。
- **どの管理グループにも入っていない人は、何も見えません。** 総務の人がその例です。

## 6. 2026-11-13 のあとに変わったところ

このテスト用データで試せる変更です。新しいものを下に並べています。

### 1. 組織を変えたときの「変更前」「変更後」の表（2026-11-17）

ユーザーの新規登録・編集で組織を選ぶ（変える）と、その組織に合わせて管理グループが選び直されます。前は何も知らせずに入れ替わっていました。いまは「変更前」と「変更後」を並べた表が出ます。

- 色の付いている行が、選ばれている管理グループです。「変更後」の行を押すと、選択と非選択が切り替わります。保存されるのは「変更後」です
- システム管理グループだけは赤で出ます（表でも、ユーザーの管理グループの欄でも）。組織を変えたときにシステム管理グループが外れると、その人は何も見られなくなるので、保存の前に表で確かめます
- 試しかた: 「ユーザー管理」で **テスト 営業** を開いて「編集」を押し、組織を「A社 製造部 第1課」に変えます。変更前は「A社 全体」だけ、変更後は「A社 全体」「A社 製造部」になります。保存しないで「変更を破棄」を押せば元のままです

### 2. 管理グループを選ぶ欄の選択肢が、切れずに全部見える（2026-11-17）

前は、欄がカードの下の端に近いと、開いた選択肢の下が切れて選べないことがありました。いまは選択肢をカードの外に重ねて開きます。管理グループの画面の「＋ 対象の管理グループを追加」と「＋ メンバーを追加」も同じです。

- 試しかた: 管理グループに 1 つも入っていない **テスト 総務** を「編集」で開き、管理グループの欄を押します。テスト用の 6 つを含め、選択肢が下まで全部見えれば直っています

### 3. 承認待・公開前のものは、取り込みと管理グループの変更でも直せない（2026-11-14・11-17）

製品・原材料、物質そのものは、前から「承認待の間はだれも直せない」「作成中・却下の間は作った本人だけが直せる」決まりでした。この決まりを、次のところにも揃えました。

| ところ | 前 | いま |
| --- | --- | --- |
| 組成 | 組成の編集の印があれば、承認待でも保存できた。承認する人が、ほかの人の公開前の組成を直せた | 製品そのものと同じ決まり |
| 判定の確認・上書き | 印だけを見ていた | 組成を直せる人と同じ範囲 |
| データ入出力の取り込み（製品・原材料の項目、組成、物質） | 承認待のものや、ほかの人の作成中のものを書き換えられた | 断る。断った行は理由と一緒に「読めない」行として出て、ほかの行は取り込む。今と同じ内容の行は「変更なし」で、断らない |
| 管理グループの変更 | 画面はボタンを隠していたが、開いたままの古い画面から変えられた | 断る |

- 試しかた（画面）: **テスト 開発** で入ります。自分が作った作成中の TG-PR-D-003 は、組成の「編集」のボタンが出て直せます。承認待の TG-PR-D-004 は、自分が作ったものでも組成の「編集」のボタンが出ません
- 取り込みで試すときの注意: いまのテスト用データには、取り込みで試せる組み合わせがありません。「データを取り込める」を持つのは品証だけで、品証が組成を直せる製造部には承認待の製品が無いためです。試すときは、テスト 開発の管理グループ（A社 開発部）に「データを取り込める」を付けるか、製造部の製品を 1 つ申請して承認待にします。断られた行は理由と一緒に出ます。何も変えずに取り込み直した行は「変更なし」です
- システム管理グループの人も、承認待のものは直せません（作成中・却下のものは直せます）

### 4. 2要素認証を必須にしたときの、パスキーだけの人（2026-11-17）

システム設定の「2要素認証（認証アプリまたはパスキー）を必須にする」を入にしている間、パスキーだけを登録している人は、パスワードだけではログインできません。「パスキーで入る」から入ります。前はパスワードだけで入れていました。認証アプリを登録している人と、まだ何も登録していない人の動きは変わりません。

- 試すときの注意: この設定は全員に効きます。chem.ca-japan.jp で入にすると、テスト用でない人にも効くので、試したら元に戻します

### 5. パスワードを忘れても、パスキーで確かめて作り直せる（2026-11-22）

パスキーを登録している人は、今のパスワードを忘れても、自分で新しいパスワードに変えられます。前は管理者に発行し直してもらうしかありませんでした。

- 試しかた: テスト用のユーザーにパスワードを設定して入り、「自分用の設定」でこの端末をパスキーに登録します。ログアウトして「パスキーで入る」から入り、「パスワードを変更する」で「パスワードが分からないときは、パスキーで確かめて変更できます」を押します。新しいパスワードを 2 回入れて「パスキーで確かめて変更」を押し、指紋・顔・PIN で確かめると変わります
- 変えると、ほかの端末のログインはすべて解除されます。アクセス記録には、パスキーで変えたことと端末の名前が残ります
- パスキーを登録していない人には、この案内は出ません

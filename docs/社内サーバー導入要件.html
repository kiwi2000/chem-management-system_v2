ケミカルコンプライアンス支援システム
社内サーバーに置くために必要なもの

このシステムを御社の社内LANのサーバーに置くとき、事前にご用意いただくものと、ネットワークの条件をまとめたものです。 導入を決める前の確認と、サーバーの準備にお使いください。実際の作業の手順は、別にお渡しする「社内サーバー導入手順書」にあります。

置き場所 社内LANのサーバー 1台 インターネット 不要 導入の作業 約1時間 版 2026-10-16

1. 全体の形

サーバー1台に、画面・判定・データベースのすべてが入ります。社員の方はパソコンのブラウザで開くだけで、パソコンにソフトを入れる必要はありません。 社外とのやり取りはなく、インターネットに繋がっていなくても動きます。

2. サーバー

項目最低推奨
CPU4コア8コア
メモリ8 GB16 GB
ディスクSSD 250 GBNVMe SSD 500 GB
形物理でも仮想でも構いません。他の業務と同居させる場合は、上の量をこのシステム用に空けてください

OS は次のどちらかです。アプリは同じもので、入れ方だけが違います。

A. Linux（推奨）

  • Ubuntu Server 24.04 LTS、または RHEL 系 9（AlmaLinux・Rocky Linux）
  • Docker の上で動かします（導入の手順で入れます）
  • インターネットに繋がらない場合は、実行用のファイル（Docker のイメージ）を別にお渡しします。Docker 本体は OS の提供元のものを入れていただきます

B. Windows Server

  • Windows Server 2019 / 2022 / 2025
  • Hyper-V・WSL・Docker は使いません。必要なソフトはすべて導入セットに入れてお渡しします
  • Linux 版ほどの運用実績はありません。どちらでもよい場合は A をお勧めします
そのほか内容
電源無停電電源装置（UPS）。停電でデータベースが壊れることを防ぎます
時刻社内の時刻サーバーなどで合わせておくこと。記録の時刻とバックアップ、2要素認証に使います
管理者の権限導入と更新には、サーバーの管理者権限（Linux は sudo、Windows は Administrator）が要ります
ウイルス対策Windows Server では、アプリとデータベースのフォルダーをリアルタイム検査の対象外にすることをお勧めします（書き込みが遅くなるため）

3. ネットワーク

通信向き相手要否
HTTPS 443社内 → サーバー利用者のパソコン開ける
HTTP 80社内 → サーバー利用者のパソコン（HTTPS へ転送するだけ）開ける
SSH 22 / RDP 3389社内 → サーバー管理者のパソコン（保守用。御社の決まりで）任意
データベース・アプリの内部—サーバーの中だけで使います開けない
インターネットから社外 → サーバー—開けない
サーバーから外へサーバー → 社外動かすためには不要。OS の更新を当てるとき、Linux でアプリをその場で組み立てるとき（導入・更新の作業中だけ。実行用のファイルを使えば不要）任意
IPアドレス社内LANの固定IPアドレスを1つ。変わると、社員の方が開けなくなります
名前社内DNSに名前（例 chem.社内ドメイン）を登録することをお勧めします。指紋や顔でのログイン（パスキー）は、名前で開かないと使えません
証明書サーバーが社内用の証明書を自分で作ります。そのサーバーの「ルート証明書」を各パソコンに登録すると、ブラウザの警告が消えます（グループポリシーで配れます）
社外から使う想定していません。必要な場合は、御社の VPN で社内LANに入ってから開いてください

社外の日本のアドレスから接続があったときだけ、記録に接続元の組織名を出すため、日本のアドレスの登録機関（JPNIC）に問い合わせます。社内LANの中だけで使う限り、この問い合わせは起きません。

ブラウザMicrosoft Edge または Google Chrome の最新版。パソコンにソフトを入れる必要はありません
台数20名ほどまでを想定しています。それを超える、または製品が数万件になる見込みがある場合は、事前にご相談ください
証明書上の「証明書」の登録をしておくと、警告なしで開けます

5. データとバックアップ

量の目安アプリ一式が約 2 GB。データベースは法規制のデータを入れて数 GB で、製品・判定・記録の量に応じて増えます
守るもの設定のファイル（データベースのパスワードを含む）と、毎日のバックアップ。この2つがあれば、別のサーバーで同じ状態に戻せます

6. 作業の分担

御社にご用意いただくもの

  • サーバー（2）と OS のインストール
  • 固定IPアドレス・社内DNSの名前・通信の許可（3）
  • UPS、バックアップの複製先（NAS など）
  • 導入の作業をする、サーバーの管理者権限を持つ方

こちらからお渡しするもの

  • アプリ一式（Linux 用は約 2 MB、Windows Server 用の導入セットは約 1.1 GB）
  • インターネットに繋がらない Linux サーバー向けの実行用ファイル（約 2 GB）
  • 社内サーバー導入手順書
  • 法規制のデータ（導入のときにこちらで入れます）

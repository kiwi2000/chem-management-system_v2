## 1. 日本とは取り込み方が違う

**日本は法文物質名を条文から先に登録してあり、LOLI からは CAS リンクだけを取った。**
中国は条文を持っていないので、**法文物質名も LOLI から作っている**。

LOLI の `Data` はどの一覧も形が同じ。

```
"Present ([0486])" As Brucine [357-57-3]
 ~~~~~~~~~~~~~~~~     ~~~~~~~  ~~~~~~~~~
 状態と番号            項目の名前 項目の鍵
```

`As` から後ろが**目録の1項目**にあたり、行の CAS（`ListData.Cas`）がそこにぶら下がる。
中国の目録は「ブルシン」という1項目に何個ものCASが付く作りになっている。

`As` が無い行は、**行のCAS自身が1項目**。

読みかたは `scripts/lib/china-list.ts`（試験で固定してある）。

**項目数が公布されている目録と合う。**

### 区分けが取れたもの

一覧の中に段階が書かれているものは、分類として分けてある。

| 規制区分 | 分類 |
| --- | --- |
| 易製毒化学品品種目録 | Category I / II / III |
| 監控化学品目録 | Schedule 1 / 2 / 3 / 4 |

ほかは分類を持たないので `DEFAULT` にまとめている。

### 閾値

**どれも「0% を超えたら該当」。**
これらの目録は載っている物質を含むかどうかで決まり、濃度の下限を持たないため。
濃度で決まるものが出てきたら、その区分だけ数字を入れる。

## 3. 取り込めなかったもの

### CASでない鍵（1,792件）

項目の鍵が `RR-00138-7` のような**LOLI独自のまとめ番号**になっている行がある。
「Mercury compounds」のように、CAS番号を持たない総称の項目に付く。

項目そのものは作ってあるが、**CASリンクは作れない**（鍵がCASではないため）。
その項目は判定に当たらない。金属の総称は日本側の法文物質名で拾えるので、
実害は小さいと見ている。

## 5. 次に取り込むときに見ること

- **項目数を公布されている目録と突き合わせる。**劇毒化学品目録（148種）のように
  数が公表されているものは、そこで取り違えに気づける
- `As` の無い行が増えていないか。増えていれば LOLI 側の書き方が変わった合図
- まとめ番号（`RR-`）の割合。増えると判定に当たらない項目が増える

# 毒劇法の閾値を、備考の文章から判定用の欄へ移した記録

2026-08-25 実施。

## 何をしたか

毒物及び劇物指定令の但し書き（「ただし、〜％以下を含有するものを除く。」）から
濃度を取り出し、法文物質名の**判定に使う閾値の欄**へ入れた。

それまでは、この濃度が**備考の文章の中にしか無かった**。閾値の欄は全件が初期値（0〜100）で、
「どんな濃度でも該当する」という意味になっていた。判定を作れば、
**本当は該当しない濃度のものを「該当する」と答える**状態だった。
備考には正しいことが書いてあるので、画面を見ても気づけない。

## 結果

毒劇法の法文物質名 588 件のうち、備考に％を含むもの **167 件**が対象。

| 扱い | 件数 |
| --- | --- |
| 閾値を入れた（濃度だけが条件） | 143 |
| 閾値を入れた（濃度以外の条件も付く） | 16 |
| 入れなかった（但し書きの対象が別物質） | 2 |
| 入れなかった（別物質が列挙されている） | 6 |

入れかたは `下限 = 濃度（EXCLUSIVE）〜 上限 = 100（INCLUSIVE）`。
「〜％以下を**除く**」なので、**境目そのものは該当しない**。だから下限は EXCLUSIVE。

## 判断したこと

**入れないほうへ倒す。** 1つの閾値で表せないものは、間違った数字を入れるより空のままにする。
空なら「全部該当」の側に倒れるので、**見落としにはならない**（余分に拾うだけで済む）。

**厳しいほうを採る。** マイクロカプセル製剤に別の濃度が定められているもの（4件）は、
**基準のほう（厳しいほう）**を閾値にした。緩いほうを採ると、該当を見落とす。

**条件は備考に残し、目印を付ける。** 濃度以外の条件（徐放性製剤・着色・容器の容量・用途）が
付くものは、閾値を入れたうえで備考に `【条件つき除外】` を付けた。
埋めなかったものには `【閾値未設定】` を付けた。**どちらも備考を検索すれば全部見つかる。**

## 残っている危うさ

**`【条件つき除外】` の 16 件は、濃度だけで判定してはいけない。**

たとえば「硝酸タリウム〇・三％以下を含有し、**黒色に着色され、かつ、トウガラシエキスを用いて
著しくからく着味されている**ものを除く」は、着色も着味もされていない 0.2％ の製品なら
**法律上は該当する**。しかし閾値だけを見ると「該当しない」と出てしまう。

判定エンジンを作るときは、**この目印が付いたものを「要確認」として別扱いにする**こと。
条件そのものを構造化して判定に組み込むのが本筋だが、そのためには
「用途」「剤型」「加工の有無」といった製品側の属性が要る。まだ持っていない。

## 取り出しかたの決めごと（`scripts/lib/law-threshold.ts`）

- **濃度は「最初の％の直前」から後ろ向きに拾う。** 化学物質名そのものに `一・一′―` のような
  数字が入るので、名前の側から探すと必ず取り違える
- **位取りの漢数字（十・百・千）が出てきたら読まない。** 1文字1桁で読む方式では `十` を
  正しく扱えない。黙って別の数にするより、気づける形で止める
- **名前の突き合わせでは、実際に見つかった揺れだけを落とす。**
  括弧の字（〔〕と［］）、「及び」と「又は」、末尾の「〜を含有する製剤」など。
  削りすぎると、別の物質を同じものと見なしてしまう
- **名指しの手前に置かれた条件を、名前に混ぜない。**
  「容量一リツトル以下の容器に収められたものであつて、亜セレン酸〇・…％以下」のような形がある

## やり直しかた

```
npx tsx scripts/seed-dokugeki-thresholds.ts          下見（書き込まない）
npx tsx scripts/seed-dokugeki-thresholds.ts --write  書き込む
```

**人が手で入れた閾値は上書きしない**（初期値のままのものだけを対象にする）ので、
何度実行しても直した内容は消えない。備考の目印も入れ直しになるだけで増えない。

## 次にやるとよいこと

同じ形の但し書きは、**他の法令にもある**。化管法・安衛法にも「〜％以上を含有するもの」
「〜％未満を除く」といった記述があるので、同じやりかたで構造化できる。
そのときは `law-threshold.ts` に形を足していく（試験も一緒に足す）。

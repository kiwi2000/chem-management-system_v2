## 気づいた点

### 訳語の揺れ（仮訳の中）

- 「カットオフ値／濃度限界」: 脚注 1 で同意義と明記。表題は「カットオフ値／濃度限界」、本文は「カットオフ値または濃度限界」「カットオフ濃度レベル」も。
- 危険有害性区分: 定義文の中でさえ「有害性区分」「危険性区分」と揺れる。表の中は「区分 1」のように「区分」だけ。
- 危険有害性クラス / 有害性クラス。
- 分類基準（章の見出し）と判定基準（表の列見出し）。英語はどちらも criteria。
- 段階的アプローチ / 段階的なアプローチ（図 3.1.1 の表題）。
- 考慮すべき成分（3.1.3.3 の定義）/ 関連成分（加算式・第 4.1 章）。英語は relevant ingredients。
- M factor: 表 4.1.5 は「毒性乗率 M」、4.1.3.5.5 の本文は「M 因子」。
- 証拠の重み付け / 証拠の総合的な重み付け。
- 物理状態（表 1.5.2）/ 物理的状態（本文）。
- 製品特定名（第 1.2 章・A4.3.1.1）/ 製品特定手段（表 1.5.2）。
- ラベル要素 / ラベル表示要素（表 2.10.2・表 2.13.2 などの表題）。
- SDS の小見出しは表 1.5.2 と附属書 4 で訳が違う（消火剤、消火作業者/消防士、管理指標/管理パラメーター、混触危険物質/混触禁止物質、国連品名/国連出荷名、輸送における危険有害性クラス/輸送時の危険性クラス など）。
- 「ばく露」は仮訳では全部ひらがな。「暴露」は 0 か所。
- 粉塵（定義）/ 粉じん（表 1.5.2 の「粉じん爆発危険性」）。
- 附属書 1 の「Not applicable」と「Not required」はどちらも「要求されない」。

### システム（catalog-data.ts / ja.ts）との主な違い

- 爆発物: システムは不安定爆発物・等級 1.1〜1.6（旧体系）。改訂 9 版は区分 1・2A・2B・2C。
- 加圧下化学品（2.3.2、区分 1〜3）がシステムに無い。章の名前も「エアゾールおよび加圧下化学品」になっている。
- 可燃性ガス: 改訂 9 版は区分 1A（自然発火性ガス・化学的に不安定なガス A/B を含む）・1B・2。システムは 1・1A・1B・2 を持ち、自然発火性ガスと化学的に不安定なガスを別クラスにしている。
- 「〜化学品」: システムの 自己反応性化学品 / 自己発熱性化学品 / 水反応可燃性化学品 / 金属腐食性化学品 に対し、仮訳は「〜物質および混合物」「金属腐食性」。
- 特定標的臓器毒性: システム「（単回暴露）」「（反復暴露）」（漢字・丸括弧）、仮訳「－単回ばく露」「－反復ばく露」（ひらがな・ダッシュ）。
- 水生環境有害性: 仮訳は「水生環境有害性、短期（急性）」と読点、区分は「急性 1」「慢性 1」。システムは空白区切り、区分は「1」。
- 急性毒性: 仮訳は 1 クラスの中で経路を分ける。システムは経路ごと（吸入はガス・蒸気・粉塵ミストまで）に別クラス。
- 生殖毒性の追加区分: 仮訳「追加区分 授乳に対するまたは授乳を介した影響」、システム「追加区分（授乳）」。
- 高圧ガスの「種類の記載なし」はシステム独自（EU 附属書 VI 対応）。
- 結果の言い方: 「区分に該当しない」「分類できない」はシステムの status の文言と同じ。システムの「分類対象外」に当たる決まった言い方は原文・仮訳に見つからなかった。
- 皮膚腐食性／刺激性・眼: スラッシュの幅。仮訳は章見出しが全角「／」、目次と附属書 1 は半角「/」。システムは全角。

### 文字起こしの癖（読むときの注意）

- 目次と一部の表で先頭のカタカナが落ちる（燃性ガス＝可燃性ガス、アゾール＝エアゾール、ゾン層＝オゾン層、スボンベ＝ガスボンベ）。
- 「濃度」の「濃」が行頭で落ちて「度限界」になる所がある。
- 「ATE」が「AT図」、表番号が「表8。l。2」のように化けることがある。
- 「GHS」「IMO」「n-」「log」など英数字の直後の日本語 1〜2 文字が落ちる（GHS|要素＝GHS ラベル要素、IMO|書＝IMO 文書、n-|クタノール＝n-オクタノール、log|）＝log 値）、「粘性率」の前の「動」が落ちる（動粘性率）。表 1.5.2 の該当箇所は PDF p.43・44 の画像で確かめて直した。
- 各ページ末尾に OCR の読み直し（「Al。1 爆発物」「GlH[S」など）が付いているが、そこからは採っていない。

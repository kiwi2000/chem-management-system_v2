### 番号を取り違えかけた2か所

**化管法には番号が2種類ある。**

```
Specific class 1 Control No. 406 ... (Ordinance No. 459, [Polychlorinated biphenyls])
                            ↑LOLI独自の管理番号        ↑政令番号（こちらと同じもの）
```

`Control No.` はLOLI独自のもので、こちらの政令番号とは別物。ポリ塩化ビフェニルで確かめたところ、
こちらの第一種指定化学物質459番がポリ塩化ビフェニル、`Control No. 406` は
「四―ターシャリ―ブチルシクロヘキシル＝アセタート」という無関係の物質だった。
**`Ordinance No.` を使う。**

**安衛法の表示・通知は「則別表第2」を使う。**
令別表第9（LOLI 9905 / 9907）は号が33しかなく、こちらの2,275番までとは合わない。
則別表第2（LOLI 9906 / 9908）が2,444号あり、こちらと同じ体系だった。

## 3. 取り込めなかったもの

### 区分ごと入らなかった3つ

いずれも**LOLI側に突き合わせる番号が無い**ため。取り込みの不備ではない。

| 区分 | 理由 |
| --- | --- |
| 安衛法 特別管理物質 | 特化則の一覧（2226）に第1類・第2類・第3類の印はあるが、特別管理物質かどうかの印が無い |
| 毒劇法 特定毒物 | LOLI 1015 で `Specified` の行が全体で1件しかない |

### 有機溶剤だけ、番号を使わずに入れた

LOLI 1813 は `Class 2 Organic Solvent` としか書かれておらず、**第何号かが分からない**。
第1種／第2種／第3種の別しか取れず、番号では突き合わせられない。
LOLIの親の名前も粒度が合わない（「コールタールナフサ」1件に対し、
LOLI側は石油留分の名前が数十種類に散る）。

そこで、**有機溶剤はほぼすべて表示対象物質・通知対象物質でもある**ことを使い、
そちらに結び付いたCASを法文物質名を頼りに引いてきた。同じ法令の同じ表記どうしなので
取り違えにくく、44件しかないので目でも確かめられる。

- 44件のうち **24件は表記が完全に一致**した
- 書き方が違う16件は対応表に書いていたが、**2026-08-26 に不要になった**。
  LOLI の `ListData.XML` の `refno` に号番号が入っていると分かり、番号で結べるようになった
  （漢数字と算用数字、中黒とカンマ、「ノルマル」と「n-」の違い）
- 結果 **35 / 44 件**に結び付いた

引けなかった9件:

| 号 | 名称 | 理由 |
| --- | --- | --- |
| 3 | イソプロピルアルコール | 則別表第2に載っていない |
| 15 | 酢酸イソブチル | 同上 |
| 16 | 酢酸イソプロピル | 同上 |
| 17 | 酢酸イソペンチル（別名酢酸イソアミル） | 同上 |
| 10 | オルト―ジクロルベンゼン | 相手の法文物質名にCASが結び付いていない |
| 28 | 一・二―ジクロルエチレン（別名二塩化アセチレン） | 同上 |
| 41 | 二―ブタノール | 同上 |
| 52 | 石油ベンジン | 同上 |
| 54 | ミネラルスピリツト（…） | 同上 |

なお、こうして入れたCASも**データソースはLOLIのまま**にしている。
元をたどればLOLIから来たものであるため。

### 行として落としたもの

**CAS番号の形をしていない行**を落とした。LOLI の `Cas` 欄には次のものが混ざる。

- `UN2729` … 国連番号
- `P-96-1262` … 届出番号
- `RR-211640-7` … LOLI社内の登録番号

判定はCAS番号で突き合わせるため、これらを入れても当たらない。件数は取り込みのたびに表示する。

### 番号が合わなかったもの

| 区分 | 合わなかった鍵の種類 | 補足 |
| --- | ---: | --- |
| 毒劇法 毒物 | 2 | `2-1-103`、`2-1-70`。毒物の行に劇物の書き方が混じっている |
| 毒劇法 劇物 | 21 | |
| 安衛法 表示対象物質 | 192 | 2,444号のうち。こちらに無い号 |
| 安衛法 通知対象物質 | 191 | 同上 |

化審法・化管法は**すべての区分で0件**。番号の体系がそのまま一致した。

### 特定一般化学物質が 5 / 14 にとどまった理由

LOLI 10077 は11行しかなく、こちらの14件のうち9件しか載っていない
（`7-4076`・`7-4077`・`7-4081`・`7-4082`・`1-1273` は未収載）。
さらにそのうち4件はCAS番号ではなくLOLI社内番号だったため、結べたのは5件。

## 4. 次に取り込むときに見ること

- **番号の体系が変わっていないか。**LOLIは版ごとに書き方を変えることがある。
  上の「LOLI側の書き方」と実物を見比べる
- **鍵の種類数がこちらの件数と合うか。**取り込み前に数を数えると、
  番号を取り違えていればその時点で分かる（化管法は515・23・134でぴったり合った）
- **同じ版・同じデータソースへの取り込みは入れ替え。**前の中身は消えるので、
  途中で止めると欠けたまま残る
